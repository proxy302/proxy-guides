# ISP 代理和住宅代理有什么区别？

ISP 代理是登记在消费级互联网服务商名下、但跑在服务器上的 IP，持有期间地址不变；（动态）住宅代理用的是真实家庭宽带上的地址，通常每个连接换一次。一句话：ISP 代理固定，住宅代理轮换。所以 ISP 代理也被叫作「静态住宅代理」。

## 为什么叫「ISP 代理」

名字来自地址登记在谁名下。数据中心 IP 属于机房公司；家庭 IP 属于消费级运营商。ISP 代理像家庭 IP 一样登记在消费级运营商名下，又像数据中心 IP 一样跑在服务器上，而且不会变。其他代理厂商的说法也一致：登记在 ISP 名下，物理上放在机房里。

标签你可以自己查。IP 数据服务会给网络背后的机构分类：IPinfo 的 ASN 数据分为 isp、hosting、business、education、government，MaxMind 的数据有 residential、cellular、hosting 等用户类型。两个数据库对同一个网络的标注可能不同，而且两家也都卖代理识别服务，所以没有哪种类型是完全看不出来的。

## 什么时候选哪种

**选动态住宅：** 任务是大量互不相关的请求，比如抓公开网页、从不同国家查搜索结果或广告、监控价格。按用掉的流量付费，不需要两次用同一个地址。

**选静态 ISP：** 要反复登录同一个账号、店铺或后台。每次地址都该一样，并且在账号所属的国家。

**选数据中心：** 流量很大，而且目标网站接受机房地址。它是最便宜的固定 IP，但有些网站对机房地址和家庭地址的对待不同，请先拿你的目标测一测。

已登录的账号不要用轮换 IP，否则账号每次连接都像从不同地址上来。短时间的登录流程如果非用动态住宅，请用固定一个国家的粘性会话，不要用全球轮换。

## 常见混淆

- **「住宅」不等于「静态」。** 住宅说的是地址属于谁；静态或轮换说的是会不会变。ISP 代理既是住宅登记，又是静态。
- **「ISP 代理」不是「你自己家的宽带」。** 它是登记在运营商名下的代理 IP。
- **住宅标签不是保证。** 平台仍可能根据 IP 的历史和你的行为区别对待。代理只改变网络地址，不改变平台规则，也不改变账号本身的状态。
- **静态不一定更好。** 如果不登录账号，动态住宅通常更省钱。

## 快速判断

1. 要登录账号吗？要：静态 ISP，一号一个。不要：往下。
2. 需要很多不同出口，或要从多个国家看内容吗？要：动态住宅。
3. 是对接受机房地址的网站跑大流量吗？是：数据中心。
4. 拿不准：买最小的（1 GB 动态住宅或 1 个 IP 用 1 天），拿真实目标测。

## 常见问题

**ISP 代理和静态住宅代理是一回事吗？** 实际使用中是。

**哪个最便宜？** 按 IP 算是数据中心；请求很多时是动态住宅，US$1.50/GB 起。

**网站能看出住宅 IP 是代理吗？** 有时能。IP 数据公司出售住宅代理标记。给每个账号用一个稳定、干净、国家正确的 IP，比标签本身更重要。

**抓取该用数据中心还是住宅？** 目标接受服务器 IP 时用数据中心，更快更便宜；目标封机房段时换动态住宅。请遵守各网站的条款和 robots 规则。
