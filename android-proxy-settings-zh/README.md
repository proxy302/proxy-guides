# 安卓手机 Wi-Fi 代理怎么设、怎么验证

先说结论：安卓系统自带的 Wi-Fi 代理只有三栏——代理服务器主机名、代理服务器端口、不使用代理的网址，没有用户名和密码栏，所以需要账号密码的代理填不进系统 Wi-Fi 代理。要用带账密的代理，有两个办法：装一个支持代理认证的应用，把账密填在应用里；或者在支持代理设置的浏览器里单独配置，只让这个浏览器走代理。系统 Wi-Fi 代理适合不需要账密的 HTTP 代理，设好后在 Chrome 里打开 `https://ipinfo.io/json`，看到代理的 IP 和国家就是生效了。本指南由 Proxy302 维护，我们也卖这些代理：静态 ISP 1 天 0.5 美元、30 天 7.99 美元，所有国家同价，30 天及以上的静态 IP 是你独享的。

## 系统 Wi-Fi 代理：能做什么、不能做什么

| 项目 | 情况 |
|---|---|
| 支持的协议 | HTTP |
| 用户名、密码 | 没有这两栏 |
| 生效范围 | 只对设置的这个 Wi-Fi；换个 Wi-Fi 或用移动数据都不走 |
| 哪些应用会用 | 系统界面会提示：浏览器会使用这个 HTTP 代理，其他应用不一定使用 |

对比一下 iPhone：iPhone 的 Wi-Fi 代理「手动」里有「鉴定」开关，可以填用户名和密码，但也只支持 HTTP。见[iPhone 设置代理](../iphone-proxy-settings/README.md)（英文）。

## 步骤：设置不需要账密的 HTTP 代理

各品牌菜单名字不太一样，大致是：

1. 打开「设置」→「网络和互联网」（有的手机叫「WLAN」或「连接」）。
2. 找到当前连着的 Wi-Fi，点旁边的齿轮，或长按选「修改网络」。
3. 展开「高级选项」。
4. 「代理」选「手动」。
5. 填「代理服务器主机名」和「代理服务器端口」；「对以下网址不使用代理」里可以留空。
6. 保存。

关掉时回到这里，把「代理」改回「无」。

## 带账密的代理怎么用

**办法一：用支持代理认证的应用。** 在应用里新建一个代理配置，填主机、端口、用户名、密码，开启后它负责整机或指定应用的流量。注意应用支持哪种协议，有的只支持 SOCKS5，就要买 SOCKS5 的 IP。Proxy302 有自己的安卓 App，在控制台「工具与检测 → 移动端 APP」里下载；用别的应用也可以，挑能填用户名和密码的。

**办法二：在浏览器里单独配置。** 有的浏览器自带代理设置或支持代理扩展，可以在浏览器里填带账密的 HTTP 代理，只影响这个浏览器，其他应用照常直连。

两种办法第一次开启时，系统可能弹出连接请求，确认后才生效。

## 怎么验证

1. 先在电脑上确认代理本身能用：

   ```bash
   curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   USER、PASS、HOST、PORT 是占位符；SOCKS5 的 IP 换成 `socks5h://`。电脑上通、手机上不通，问题就在手机这边的设置。
2. 手机上用要验证的那个浏览器或应用打开 `https://ipinfo.io/json`，看 `ip`、`country`、`org`。
3. 显示的是自己的 IP，说明没走代理：检查是不是连的另一个 Wi-Fi、是不是在用移动数据、应用里的代理有没有开启。

## 常见问题排查

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 系统 Wi-Fi 代理填好后网页打不开 | 代理需要账密，系统这一层填不了 | 改用支持认证的应用，或在浏览器里单独配置 |
| 浏览器走了代理，某个 App 没走 | 系统 Wi-Fi 代理不保证所有应用都用 | 用支持认证的应用接管该 App 的流量 |
| 应用里连不上 | 协议不对，比如应用只支持 SOCKS5 而 IP 是 HTTP | 按应用支持的协议购买 |
| 报 407 | 账密错了 | 从「我的资产」重新复制 |
| 出门就失效 | 系统 Wi-Fi 代理只管这一个 Wi-Fi | 用应用接管，移动数据下也能用 |
| 昨天好的今天不行 | IP 到期被收回 | 提前续费或开自动续费 |

## 常见问题

**系统 Wi-Fi 代理为什么没有密码栏？** 安卓系统自带的界面就是这样设计的，只有主机名、端口和例外网址。

**移动数据能走代理吗？** 系统 Wi-Fi 代理不行。用支持认证的应用，Wi-Fi 和移动数据都能走。

**一个 IP 能给几个 App 用吗？** 同一个人、同一个账号体系可以；不同人的账号别挤在一个 IP 上。

**有免费试用吗？** 没有。最便宜的测试是一个静态 ISP 用 1 天，0.5 美元。
