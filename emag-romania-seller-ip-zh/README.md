# 在 eMAG 罗马尼亚站开店，卖家后台登录和 API 对接分别用什么 IP？

分两件事看。后台登录：团队在罗马尼亚办公，就给每个 eMAG 卖家账号配一个罗马尼亚静态 ISP（静态住宅）IP，长期不换，只在专门开后台的浏览器配置里用，再打开后台的两步验证。API 对接：ERP、上架或订单工具调用 eMAG API 时，要从固定 IP 发出，并把这个 IP 填进卖家后台 My account › Profile › Technical details 的「Seller IPs」；对接程序跑在有固定公网 IP 的服务器上，直接填服务器的 IP 就行，不需要代理。本指南由 Proxy302 维护，我们也销售这些代理：罗马尼亚静态 ISP 1 天 0.5 美元、30 天 7.99 美元，所有国家同价，30 天及以上的静态 IP 由买家独享。能不能入驻、要交哪些资料、审核怎么走，由 eMAG 决定，IP 改变不了。

## 后台登录为什么要固定 IP

卖家后台每天要处理订单、库存、报价和退货，常常是几个人在几个地方打开：仓库、办公室、家里、手机热点。每换一个网络，账号这边看到的就是一个新地址。把后台工作收进一个固定罗马尼亚 IP 的浏览器配置里，账号就只有一个稳定出口。

国家跟着实际办公的地方走：团队在罗马尼亚就用罗马尼亚 IP；团队在别的国家，用所在国家的 IP（我们卖的国家见[支持国家列表](https://proxy302.com/zh/locations/)）。不要为了显得像本地卖家去挑罗马尼亚 IP。

eMAG 卖家后台的帮助中心有开启两步验证（2FA）的说明，后台账号建议都打开。

## API 对接为什么要固定 IP

按 PlentyONE 等对接工具公开的 eMAG 设置说明，接入时要登录 eMAG 卖家后台，进入 My account › Profile › Technical details，把调用 API 的 IP 地址加到「Seller IPs」里。也就是说，调用方的出口 IP 一变，接口就可能不认。具体字段以你后台里看到的页面为准。

怎么选：

| 对接程序跑在哪 | 用什么 |
|---|---|
| 有固定公网 IP 的云服务器或机房服务器 | 直接把服务器 IP 填进 Seller IPs，不用代理 |
| 办公室电脑、笔记本、没有固定 IP 的家用宽带 | 让程序走一个静态 IP，再把这个 IP 填进去 |
| 第三方 SaaS 工具代你调用 | 填工具方给的 IP，按他们的说明来 |

程序怎么设置代理，看[需要 IP 白名单的接口用什么代理](../fixed-ip-for-api-allowlist/README.md)。API 白名单只看地址固不固定，不太讲究国家；但后台登录和 API 用同一个罗马尼亚 IP 也没问题，台账更好记。

## 后台登录的配置步骤

1. **一个卖家账号买一个罗马尼亚静态 ISP。** 协议下单时定：浏览器扩展、系统代理用 HTTP；指纹浏览器环境多用 SOCKS5。
2. **建一个只开 eMAG 后台的浏览器配置。** 单独的 Chrome、Edge 个人资料，或指纹浏览器里的一个环境。
3. **填代理：** 主机、端口、用户名、密码照订单页填，协议一致。
4. **登录前看出口。** 在这个配置里打开 `https://ipinfo.io/json`，`country` 应为 `RO`。终端里：

   ```bash
   curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   USER、PASS、HOST、PORT 是占位符；SOCKS5 的 IP 用 `socks5h://`。
5. **登录后打开两步验证。**
6. **按 IP 打开自动续费。** 到期不续，IP 会被释放，重新买到的是另一个地址；如果这个 IP 还填在 Seller IPs 里，记得同步改。
7. **记台账：** 卖家账号、登录用的 IP、API 用的 IP、浏览器配置名、续费日期。

## eMAG 要求核验时

照入驻时提交的公司登记、负责人和收款资料如实回复，走 eMAG 的官方渠道。代理只管网络出口，和核验无关。

## 出问题先看这里

| 现象 | 可能原因 | 处理 |
|---|---|---|
| ipinfo 显示的不是 RO | 浏览器配置没走代理，或叠了其他全局网络工具 | 只留一层代理 |
| 代理检测失败 | HTTP、SOCKS5 填反 | 按订单页的协议改 |
| 407 或一直弹认证框 | 代理用户名、密码错 | 从订单页重新复制 |
| API 突然被拒，账号密码没变 | 调用方出口 IP 变了，或静态 IP 到期换了地址 | 核对实际出口 IP，和 Seller IPs 里的对一下 |
| 之前能登录，今天连不上代理 | IP 到期被释放 | 提前续费或开自动续费 |

## 常见问题

**后台登录和 API 能共用一个 IP 吗？** 可以，都是同一家店的流量。分开也行，看你们哪种好管。

**团队里几个人能同时用这个 IP 登后台吗？** 可以，同一家店的同事在同一个浏览器配置里工作，出口是一个 IP。

**罗马尼亚选哪个城市？** 国家对就行。购买页能选城市时，挑离办公室或仓库近的，选了就别换。

**有免费试用吗？** 没有。最小购买是 1 个静态 IP 用 1 天，0.5 美元。
