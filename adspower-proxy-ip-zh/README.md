# AdsPower 代理 IP 怎么买、怎么配？

给 AdsPower 的每个浏览器环境配一个独立的代理 IP：需要长期登录的账号买静态 ISP（静态住宅）IP，只看公开页面的买按 GB 的动态住宅。在环境设置里选自定义代理，类型选 HTTP 或 SOCKS5，填主机、端口、用户名、密码，点检测。这篇由 Proxy302 维护，我们卖这类 IP：静态 ISP 1 天 US$0.50，30 天 US$7.99；动态住宅普通线 US$1.50/GB。没有免费试用。

## 买哪种

| | 静态 ISP | 动态住宅 |
|---|---|---|
| 地址 | 租期内固定 | 每个连接换，或保持会话 |
| 计费 | 按 IP 加租期 | 按 GB，预付流量不过期 |
| 适合 | 一个环境对应一个长期登录的账号 | 看公开页面、查价格、采集 |
| Proxy302 起价 | 1 天 US$0.50 | US$1.50/GB |

动态住宅预付更便宜：50 GB 每 GB US$1.42，100 GB 每 GB US$1.35，300 GB 每 GB US$1.20，500 GB 每 GB US$1.124。

## 配置步骤

下面按通用流程写，菜单名称以你电脑上 AdsPower 的界面为准。

1. **在 Proxy302 下单。** 选静态 ISP，选国家、租期和数量，一个环境一个 IP。选协议：HTTP 或 SOCKS5，一个 IP 只有一种。
2. **复制四项。** 在「我的资产」里复制该 IP 的主机、端口、用户名、密码。
3. **新建环境，填代理。** 在代理设置里选自定义代理，类型要和 IP 的协议一致，把四项分别填进去。主机栏不要带 `http://` 之类的前缀。
4. **点检测。** 软件的检测通过后，还要自己确认一次出口：打开环境，在窗口里访问查 IP 的网页，看国家和你买的一致。
5. **再登录账号。** 确认无误再打开目标网站。

命令行也可以先测：

```
curl -x socks5h://USER:PASS@HOST:PORT https://ipinfo.io/json
```

HTTP 的 IP 用 `http://`。看 `country` 和 `org`。

## 批量建环境时的顺序

账号多的时候，容易在复制粘贴里串号。比较稳的顺序是：先在 Proxy302 一次买够数量，导出或逐个记下每个 IP 的四项信息，在表格里写上它对应的环境名和账号名；再回到 AdsPower 逐个新建环境、填代理、点检测；每建完一个就在窗口里查一次出口，再进入下一个。这样出现 407 或国家不对时，能马上知道是哪一个环境的哪一项填错。

## 检测失败怎么排查

| 现象 | 先查 |
|---|---|
| 检测失败 | 类型与 IP 协议是否一致，四项是否完整 |
| 407 | 用户名或密码错，用这个 IP 自己的账密 |
| 昨天能用，今天不行 | 租期到期了，看到期日 |
| 出口国家不对 | 本机有其他全局网络工具叠在上面，关掉 |

## 环境与账号的习惯

- 一个账号一个环境，一个环境一个 IP，不要把两个账号放进同一个 IP。
- 这个号一直用这个 IP，不要随意换。
- 到期前续费，保留同一个 IP；可以按 IP 开自动续费。过期的 IP 会被收回。
- 在 AdsPower 里设了代理，就别再在系统里开别的全局网络工具。
- 平台要求验证，就如实完成。代理只提供稳定出口。

批量建环境时，一单最多买 100 个 IP，建议按环境名给每个 IP 加备注，避免对错号。更多通用原则看[指纹浏览器配家宽 IP](../antidetect-browser-with-residential-ip/README.zh-CN.md)。

## 常见问题

**AdsPower 自带代理吗？** 这里只讲自己买 IP 再填进去的做法。

**选 HTTP 还是 SOCKS5？** 两者都能用，注意工具支持。指纹浏览器环境多选 SOCKS5；下单时选定后不能在同一个 IP 上切换。

**一个 IP 能给两个环境吗？** 不建议，一个账号一个 IP。

**30 天的 IP 是独享的吗？** 30 天及以上的静态 IP 是你独享的。
