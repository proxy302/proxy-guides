# 亚马逊店铺能用静态 IP 吗？买哪种、怎么配

能用。登录亚马逊卖家后台（Seller Central）适合用静态 ISP IP：每个卖家账户一个，长期不换，放在只给这个账户用的浏览器配置里。本文由 Proxy302 维护，我们出售文中提到的 IP：亚马逊专用 ISP 30 天 12 PTC（1 PTC = 1 美元），首个 IP 半价，交付前检测、确认不是数据中心地址；也可以用通用静态 ISP，30 天 US$7.99，1 天 US$0.50。IP 只让合规账户的登录地址保持一致。按亚马逊的政策，每个地区原则上只能有一个卖家账户，有正当业务需要才可以再开；平台要求验证时，靠提交真实资料通过，和 IP 无关。

## 买哪种

| 选项 | 适合 | 价格（Proxy302） | 说明 |
|---|---|---|---|
| 亚马逊专用 ISP | 卖家后台日常登录 | 30 天 12 PTC，首个 6 PTC | 交付前检测，确认不是数据中心地址 |
| 通用静态 ISP | 同样的用途，或店铺同时在别的平台 | 30 天 US$7.99；1 天 US$0.50 | 各国同价，可先买 1 天验收 |
| 动态住宅 | 不登录，看自己的商品在别的站点怎么展示 | US$1.50/GB | 地址会变，不用来登录后台 |
| 数据中心 | 不建议登录后台 | 静态 1 天 US$0.25 | 查询时显示机房地址 |

两种 ISP 都是租期内地址不变，30 天及以上的静态 IP 为购买者独享。只做亚马逊、想要交付前就检测过的，选亚马逊专用 ISP；手上同时有其他平台店铺、想统一管理的，用通用静态 ISP。

## 怎么配

1. **先数账户。** 列出你按亚马逊政策有权经营的卖家账户，一个账户买一个 IP。北美、欧洲的统一账户在一个卖家后台里管多个站点，按账户算，不按站点算。
2. **定一个长期不变的位置。** IP 的作用是让登录地址稳定，不是让账户看起来在注册资料以外的地方经营。选定后不要来回换。
3. **建一个专用浏览器配置。** 每个账户一个配置，代理类型选和 IP 一致的 HTTP 或 SOCKS5，填入主机、端口、用户名、密码，运行软件自带的检测。
4. **登录前看出口。** 在配置里打开 `https://ipinfo.io/json`，`ip` 应与订单一致，`org` 应是宽带运营商。命令行可以先测一遍：

   ```bash
   curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   SOCKS5 的 IP 用 `socks5h://`。命令里是占位符。
5. **两步验证留给负责人。** 卖家后台的两步验证绑定在账户负责人的手机或验证器上，不要为了方便交给运营人员。
6. **员工用自己的登录。** 在卖家后台的用户权限里给每位员工单独开账号、按需授权，不要共享主账户密码。
7. **到期前续费。** 按 IP 打开自动续费。IP 过期会被收回，再买是新地址，后台的登录记录就会出现一个陌生位置。

## 日常怎么维护

- 每次打开店铺前，先在配置里看一眼出口 IP。
- 每月核对一次：哪个账户用哪个 IP、到期日、自动续费是否开着。
- IP 真出了问题（连不上，或被查成机房地址）才换，换一次之后固定用新的，并记下更换日期。
- 电脑上不要同时开其他全局网络工具，免得浏览器配置的流量走错出口。

## 亚马逊要求验证时

按通知要求提交和注册信息一致的真实资料，完成后续步骤。验证看的是资料和账户本身，IP 帮不上忙；资料不真实的申请，用什么 IP 都通不过。验证期间也别换 IP，登录记录只会更乱。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 反复收到新位置登录提醒 | 有时没走配置里的 IP，或 IP 换过 | 只从专用配置登录，固定一个 IP |
| 配置检测失败 | HTTP 和 SOCKS5 选反，或字段粘贴错 | 按 IP 的类型重选，四项重新复制 |
| 407 认证失败 | 用了别的 IP 的用户名密码 | 用这个 IP 自己的账密 |
| 上个月能用，这个月不行 | 租期结束，IP 已被收回 | 提前续费或开自动续费 |
| 两个账户出口相同 | 有人把一个配置的 IP 复制进了另一个 | 每个账户单独一个 IP |

## 常见问题

**每个账户都有独立 IP，就可以多开账户吗？** 不可以。能不能开第二个账户取决于亚马逊的政策和你的业务情况，可以问卖家支持；IP 改变不了这个答案。

**动态住宅能登录后台吗？** 不建议，地址会变，和后台需要的稳定正好相反。

**有试用吗？** 没有免费试用。第一个亚马逊专用 ISP 半价 6 PTC；通用静态 ISP 1 天 US$0.50。
