## 四种用途分别怎么判断

**账号和店铺。** 判断标准是同一个账号会不会连续几周从同一个地方登录。会，就用静态 ISP，一个账号配一个 IP，从开始用到停用都不换。30 天及以上的静态 IP 为购买者独享。HTTP 或 SOCKS5 下单时选定，一个 IP 只有一种协议。

**采集。** 请求彼此独立、不需要登录时，动态住宅最省：用多少流量付多少，预付流量不过期。要连着走几步的流程（翻页、加购后看运费），用粘性会话让出口保持一段时间；会话参数按服务商文档写，Proxy302 的控制台会直接生成。

**AI 订阅。** 只在服务官方支持、并且你本人所在的国家使用，一人一个固定 IP。IP 不改变服务方的使用政策和支持地区列表，也不能保证账号不受限。详见 [Claude 账号老被封和 IP 有关系吗](../claude-account-suspended-ip-zh/README.md)。

**测试。** 联调自己的接口、检查自己网站在海外能否打开、给监控脚本一个固定出口，这些都不需要住宅地址，数据中心 IP 更快也更便宜。只有目标网站对机房地址区别对待时，才换成住宅。

## 选之前做三项检查

1. **把任务写下来。** 每个任务标注：要不要登录、要不要固定地址、每月大概多少流量。
2. **先买最小单位。** 静态 1 个 IP 1 天 US$0.50；动态先少量按 GB 用。没有免费试用。
3. **验收再放量。** 通过 IP 访问 `https://ipinfo.io/json`，看 `country` 是否和下单时一致，`org` 是运营商还是机房。

```bash
curl -sS --max-time 20 -x "socks5h://USER:PASS@HOST:PORT" https://ipinfo.io/json
```

HTTP 类型的 IP 把 `socks5h://` 换成 `http://`。命令里是占位符。

## 常见选错

| 选法 | 后果 | 改成 |
|---|---|---|
| 用动态住宅登录店铺 | 登录地址一直在变 | 静态 ISP，一店一个 |
| 用静态 IP 跑大批量采集 | 一个地址扛所有请求，按个付租金也不划算 | 动态住宅按 GB |
| 一个静态 IP 登几个账号 | 几个账号落在同一个地址上 | 按账号数买 |
| 测试也买住宅 | 多花钱 | 数据中心 |
| 为 AI 订阅选一个自己不在的国家 | 政策看人实际所在地，IP 改变不了 | 选你所在的支持国家 |

## 常见问题

**只能买一种怎么办？** 有登录需求就先买静态 ISP；只采集就买动态住宅。

**静态住宅和 ISP 代理是一回事吗？** 实际使用中是一回事，见 [ISP 代理和住宅代理有什么区别](../isp-proxy-vs-residential-proxy/README.zh-CN.md)。

**不同国家价格一样吗？** 静态 ISP 各国同价。

**IP 到期会怎样？** 过期后被收回，再买是新地址。长期用的 IP 可以按个开自动续费。
