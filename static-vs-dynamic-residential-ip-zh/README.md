# 静态住宅 IP 和动态住宅 IP 有什么区别？怎么选

区别在两点：地址变不变、按什么计费。静态住宅 IP（也叫 ISP IP）在整个租期里是同一个地址，按个、按天计费，适合要反复登录的账号；动态住宅 IP 的出口会换（每个新连接换一次，或用粘性会话保持一段时间），按流量计费，适合采集公开数据。怎么选：先问这件事需不需要同一个地址，再按用量算钱。本文由 Proxy302 维护，我们出售文中提到的 IP，两种都卖：静态住宅 1 天 US$0.50、30 天 US$7.99，各国同价；动态住宅普通线 US$1.50/GB 起，预付流量不过期。下面用决策步骤和几笔真实价格算例说明。

## 差别在哪

| | 静态住宅（ISP） | 动态住宅 |
|---|---|---|
| 出口地址 | 租期内不变 | 新连接换一个，或在会话期内保持 |
| 计费单位 | 每个 IP × 天数 | 每 GB 流量 |
| 账单取决于 | 你有几个账号、用多久 | 你下载了多少数据 |
| 到期或用完 | 到期后 IP 被收回，再买是新地址 | 预付流量不过期 |
| 一个账号配几个 | 一个 | 不用于长期登录的账号 |

## 四步决定买哪种

**第 1 步：把任务一条条列出来。** 例如：「登录 3 个店铺后台」「每天抓 2,000 个商品页」「每周看一次 5 个国家的搜索结果」。

**第 2 步：每条任务问一句：中途换地址会不会坏事？**

- 会，而且要连续几天、几周用同一个地址：静态住宅，一个账号一个。
- 会，但只要保持几分钟（翻页、加购后看运费）：动态住宅，开粘性会话。会话参数按服务商文档写，Proxy302 的控制台会直接生成。
- 不会，每个请求互不相关：动态住宅，正常轮换。

**第 3 步：估用量。** 静态看「账号数 × 租期」；动态看「页面数 × 每页大小」。每页大小可以先用浏览器开发者工具或 `curl -w "%{size_download}"` 量几个样本页。

**第 4 步：用分界点核对。** 一个静态 IP 30 天 US$7.99，等于动态住宅普通线约 5.3 GB（7.99 ÷ 1.50）。不需要固定地址的任务，月用量远低于这个数时，按 GB 更省；需要固定地址的任务，不用比这个数，直接选静态。

## 成本算例

以下用 Proxy302 的公开价格计算，每页大小是假设值，你的实际数据会不同。

**例 1：8 个社媒账号，运营一个季度。** 每个账号一个静态 IP，买 90 天：8 × US$23.97 = US$191.76。拿不准能做多久，就先每个买 7 天（8 × US$3.50 = US$28.00），确定后再续 30 天以上。

**例 2：价格监控，每天 3,000 个商品页。** 假设关掉图片后每页约 300 KB，一天约 900 MB，30 天约 27 GB。普通线按量约 27 × US$1.50 = US$40.50；也可以预付 50 GB，每 GB US$1.42，共 US$71.00，可以用将近两个月，流量不过期。

**例 3：一个小团队，3 个店铺加少量采集。** 3 个静态 IP 30 天：3 × US$7.99 = US$23.97；每月采集约 10 GB 动态流量：US$15.00。合计每月约 US$38.97。两种分开买、分开用，店铺不走动态，采集不占静态。

**例 4：偶尔看看别国页面，不登录。** 每月约 2 GB，动态住宅约 US$3.00，比租一个 30 天静态 IP 便宜。

## 买之前的检查

1. 静态先买 1 个 IP 1 天（US$0.50），动态先少量按 GB 用。没有免费试用。
2. 通过 IP 访问 `https://ipinfo.io/json`，看 `country` 和 `org` 是否符合预期。
3. 静态 IP 的协议（HTTP 或 SOCKS5）下单时选定，一个 IP 只有一种，先确认工具支持哪种。

## 常见选错

| 选法 | 问题 | 改成 |
|---|---|---|
| 动态住宅登录店铺或社媒 | 每次登录地址不同 | 静态住宅，一号一个 |
| 静态 IP 跑整站采集 | 所有请求压在一个地址上，按个付租金也贵 | 动态住宅按 GB |
| 按最乐观的估计预付大包 | 钱先压着 | 先按量跑几天，看真实日用量 |
| 静态 IP 到期才续 | IP 被收回，账号换新地址 | 提前续，或按 IP 开自动续费 |
| 一个任务开着粘性会话就不换了 | 会话有时效，到期会换地址 | 长期固定用静态 |

## 常见问题

**静态住宅和 ISP 代理是一回事吗？** 实际使用中是：登记在运营商名下、租期内不变的地址。

**动态住宅能不能一直保持同一个 IP？** 粘性会话只能保持一段时间，要几天、几周不变就用静态。

**静态 IP 是独享的吗？** 30 天及以上的静态 IP 为购买者独享。

**两种可以混用吗？** 可以，按任务分开：账号放在静态上，采集放在动态上。
