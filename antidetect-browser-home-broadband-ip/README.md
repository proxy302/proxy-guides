# 指纹浏览器怎么配家宽 IP？

指纹浏览器里每个环境配一个家宽（静态住宅，也叫 ISP）IP：下单时选 HTTP 或 SOCKS5，在环境的代理设置里选自定义代理，填主机、端口、用户名、密码，检测通过后，在窗口里打开查 IP 的网页确认出口。这篇由 Proxy302 维护，我们卖这类 IP。静态 ISP 1 天 US$0.50，30 天 US$7.99；动态住宅 US$1.50/GB 起。没有免费试用。适合要长期用同一个账号环境的人。

## 先分清「家宽」有两种

| | 静态住宅（ISP） | 动态住宅 |
|---|---|---|
| 地址变化 | 租期内不变 | 每个连接变，可保持会话 |
| 计费 | 按个，按租期 | 按 GB |
| 指纹浏览器里适合 | 一个环境长期登录一个账号 | 临时看页面、查价格 |
| 参考价格 | 30 天 US$7.99 | 普通线 US$1.50/GB |

环境是长期存在的，每次打开都像同一个「设备」，所以账号型环境配静态更合适。

## 为什么环境和 IP 要一一对应

指纹浏览器的价值，是让每个环境保持稳定、相互独立。如果 IP 在环境之间混着用，环境各自独立这件事就没有意义。反过来，给每个环境一个固定的 IP，再把环境和账号一一记在表里，日后查问题、续费、换号都清楚。

## 配置步骤（通用）

1. 下单时一个环境买一个 IP，选好国家和租期，协议选 HTTP 或 SOCKS5。
2. 在 Proxy302 的「我的资产」里复制四项：主机、端口、用户名、密码。
3. 在指纹浏览器新建环境，代理类型选与 IP 一致，粘贴四项。主机栏不要带协议前缀。
4. 点软件里的检测按钮。
5. 打开环境，访问 `https://ipinfo.io/json`，看 `country` 是不是你买的国家。

软件的菜单名各家不同，以你装的版本为准。比特浏览器可参考[集成页](https://proxy302.com/zh/integrations/bitbrowser/)和[购买指南](https://proxy302.com/zh/guides/bitbrowser-ip-price-and-buying/)。

## 买之前和买之后的检查清单

- [ ] 国家与账号面向的市场一致。
- [ ] 协议与浏览器环境一致。
- [ ] 地址段登记方是运营商：在 ARIN、RIPE 或 APNIC 的 WHOIS 查。
- [ ] 两三个 IP 库的类型栏一致，不是 hosting。
- [ ] 查过反向解析和黑名单。
- [ ] `curl -x http://USER:PASS@HOST:PORT https://ipinfo.io/json`（SOCKS5 用 `socks5h://`）看 `country` 和 `org`。

## 容易踩的坑

| 问题 | 原因与办法 |
|---|---|
| 两个环境用了同一个 IP | 一个账号一个 IP，拆开 |
| 环境里同时开了别的全局网络工具 | 只留一层，关掉其余的 |
| IP 过期后环境连不上 | 到期前续费才能保留同一个 IP，可开自动续费 |
| 检测通过但网页显示国家不对 | 在环境窗口里再查一次，不要只看软件里的检测 |
| 407 报错 | 账密抄错，用该 IP 自己的凭据 |

## 账号卫生

一个账号一个浏览器环境；这个号一直用这个 IP；到期前续费；不要在环境之外再叠别的网络工具；改完代理马上在窗口里查出口。平台要求验证就如实完成。IP 管的是网络出口，不管平台怎么判断账号。

## 换环境、换电脑时

把环境搬到另一台电脑，或导出给同事时，代理四项通常会跟着环境一起走，IP 还是原来那一个。这时只需要确认两点：这个账号仍然只有一个人在用，换了设备后在窗口里再查一次出口。别因为换了设备就顺手换一个新 IP。
