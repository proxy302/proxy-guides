# TikTok 原生 IP 是什么，怎么买？

「TikTok 原生 IP」是个市场说法，没有官方定义。一般指：IP 的归属地和注册地都在目标国家，登记在当地的家庭宽带运营商名下，IP 库里不标成代理或机房。想长期运营一个固定市场的账号，适合买静态 ISP（静态住宅）IP。Proxy302 的静态 ISP 1 天 US$0.50，30 天 US$7.99，所有国家同价。这篇由 Proxy302 维护，我们卖这类 IP；没有免费试用，最小的购买是 1 个 IP 用 1 天。

## 「原生」到底指什么

卖家说的「原生」，大多是下面三条的合并：

1. 地址段登记在目标国家的运营商名下，不是机房或云厂商。
2. 几个常见 IP 库里，这个地址的归属国一致，类型栏是 isp 或 residential，不是 hosting。
3. 反向解析和黑名单上看不到异常。

没有哪个卖家能保证「100% 原生」，因为各家 IP 库的判断不同，平台自己怎么看一个地址我们也看不到。所以不要只信宣传，下单后自己查一遍。

## 自己怎么验证

| 检查项 | 做法 | 看什么 |
|---|---|---|
| 登记方 | 在 ARIN、RIPE 或 APNIC 的 WHOIS 查地址段 | 登记名是运营商，不是机房 |
| IP 库类型 | 在两三个 IP 库里查同一个 IP | 类型栏一致，不是 hosting |
| 出口国家 | `curl -x socks5h://USER:PASS@HOST:PORT https://ipinfo.io/json` | `country` 是你买的国家，看 `org` |
| 反向解析与黑名单 | 查反向解析记录，再查常见黑名单 | 没有明显的机房特征，没有被列入 |

HTTP 的 IP 把 `socks5h://` 换成 `http://`。命令里的 USER、PASS、HOST、PORT 是占位符。

## 常见问题

**原生 IP 一定不会被限制吗？** 不会。IP 只是账号稳定运营的一个条件，账号行为、内容和平台规则才是主要因素。

**动态住宅能当原生 IP 用吗？** 不适合登录账号。动态住宅每个连接换一次地址，更适合看公开内容；要反复登录就用静态。

**数据中心 IP 行吗？** 静态数据中心 IP 便宜（1 天 US$0.25，30 天 US$3.99），但网站能认出是服务器地址。登录账号时我们更建议静态 ISP。
