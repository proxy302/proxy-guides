# Instagram 多账号（官方：一次最多登录 10 个）用什么 IP

一个人在自己手机上管几个自己的号，用 Instagram 自带的添加账户和切换功能就行，官方帮助中心写明一次最多可以登录 10 个账户，不需要每个号单配 IP。需要固定 IP 的，是这几种情况：团队在不同地方替客户管号、经常换网络或在公共出口后面上网、每个客户的号放在单独的浏览器环境里。这时一个号（或一个客户）配一个静态 ISP IP，长期不换，不要用一直变地址的动态 IP 登录。Proxy302 的静态 ISP 1 天 0.5 美元、30 天 7.99 美元，所有国家同价，30 天及以上的静态 IP 是你独享的。本指南由 Proxy302 维护，我们也卖这些代理。IP 改变不了 Instagram 的规则，平台要求验证时，如实完成。

## 官方怎么说

Instagram 帮助中心的[添加多个 Instagram 主页并在这些主页之间切换](https://help.instagram.com/1696686240613595)（2026 年 11 月 21 日查看）：

- 添加多个账户后，可以直接在这些账户之间切换，不用退出再登录。
- 可以给同一个 Instagram 账户新建更多主页。
- 一次最多可登录 10 个账户。

网上常见「最多 5 个」的说法，现在帮助中心写的是一次最多登录 10 个，以官方页面为准。官方提供了一人多号的切换功能，说明正常管理自己的几个号本来就是被支持的用法；IP 不是这件事的前提。

## 什么时候需要固定 IP

| 情况 | 要不要单配 IP | 建议 |
|---|---|---|
| 自己手机上管自己的几个号 | 不需要 | 用 App 自带的切换 |
| 家里或公司网络稳定，在电脑上管 | 一般不需要 | 用平常的网络 |
| 团队替多个客户管号，人在不同地方 | 需要 | 每个客户一个静态 IP、一个浏览器环境 |
| 经常换网络、在公共出口后面上网 | 需要 | 给常用的号配一个静态 IP |
| 只看公开主页、不登录 | 不用静态 | 动态住宅按流量 |

## 怎么配

**电脑上（浏览器环境）：**

1. 一个客户一个浏览器环境，代理协议选和购买时一样的（HTTP 或 SOCKS5），填主机、端口、账号、密码。
2. 环境里先打开 `https://ipinfo.io/json`，国家对了再登录。
3. 这个客户的号以后只从这个环境登录。

**手机上：**

- **iPhone：** 设置 → 无线局域网 → 当前网络旁边的 (i) → 配置代理 → 手动，填服务器和端口，打开「鉴定」填用户名和密码。只支持 HTTP，只对这个 Wi-Fi 生效，移动数据不走。
- **安卓：** 系统自带的 Wi-Fi 代理只有主机名、端口和不走代理的网址，没有用户名密码栏，带账密的代理填不进去。办法见[安卓手机 Wi-Fi 代理怎么设、怎么验证](../android-proxy-settings-zh/README.md)。

先在电脑上确认代理本身能用：

```bash
curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
```

USER、PASS、HOST、PORT 是占位符；SOCKS5 的 IP 换成 `socks5h://`。

## 用号习惯

- 一个号固定一个出口，不要今天走代理、明天直连、后天换个国家。
- 不要把同一个代理同时塞进好几个客户的环境。
- 代理和其他全局网络工具只开一层。
- 到期前续费，IP 过期会被收回，再买是新地址。
- Instagram 要求确认身份、输入验证码时，如实完成。IP 帮不了验证，也解除不了限制。

## 常见问题

**一个 IP 能登几个号？** 自己的几个号在一部手机上用 App 切换，本来就是一个网络。替不同客户管号，建议一个客户一个 IP。

**动态住宅能登录吗？** 不适合，地址一直变。

**IP 选哪个国家？** 选账号主人或团队实际所在的国家，定了别换。

**有免费试用吗？** 没有。最便宜的测试是一个静态 ISP 用 1 天，0.5 美元。
