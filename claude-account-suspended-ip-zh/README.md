# Claude 账号老被封，和 IP 有关系吗？该用什么 IP？

谁能用 Claude，由 Anthropic 的[《支持地区政策》](https://www.anthropic.com/supported-countries)决定，IP 改变不了这一点：人不在支持地区，换成哪个国家的 IP 都不算被允许。Anthropic 帮助中心列出的封号原因是反复违反使用政策、在不支持的地区创建账号、违反服务条款；此外，付款异常、多人共用或被滥用过的 IP、登录地点频繁跳动，也会让账号记录看起来不正常。只有对身在支持地区的用户，IP 才有一点作用：每人一个固定 IP，让每次登录都来自同一个地址。本文由 Proxy302 维护，我们出售文中提到的 IP；给身在支持地区、需要固定出口的用户，我们的 AI 订阅 ISP（Claude 档）是 30 天 15 PTC（1 PTC = 1 美元），首个 IP 半价 7.5 PTC。它不能保证账号永不受限，被封之后请走官方申诉。

## 逐条看：哪些原因和 IP 有关

| 原因 | 和 IP 有没有关系 | 该怎么做 |
|---|---|---|
| 反复违反[使用政策](https://www.anthropic.com/legal/aup) | 没有 | 读政策，改掉违规的用法 |
| 在不支持的国家或地区创建、使用账号 | IP 改变不了，政策看的是人实际在哪里 | 不在支持地区就不要用 |
| 违反服务条款，比如把一个账号给几个人用 | 没有 | 一人一个账号，不转让、不共用 |
| 付款异常，比如拒付、扣款失败 | 没有 | 用你本人名下、服务方接受的付款方式 |
| 用了多人共用或被滥用过的出口 | 有 | 不用公共出口，换成你自己的固定 IP |
| 登录地点频繁跳动 | 有 | 固定一个地点、一个 IP |

前三条来自 Anthropic 帮助中心的《Safeguards warnings and appeals》。后三条不在那篇文章的列表里，但会让付款记录或登录记录显得异常。表里只有最后两行是 IP 能解决的。

## 身在支持地区，怎么配一个固定 IP

1. **核对名单。** 打开[支持地区页](https://www.anthropic.com/supported-countries)，确认你本人所在的国家在列表上。不在列表上的地方都不受支持。
2. **一人一个 IP。** 国家选你实际生活、工作的那个国家，不要选别的国家。
3. **只放在一处。** 放进一个浏览器配置，或者设成系统代理，二选一。电脑上不要同时开其他全局网络工具，否则出口会忽然变掉。
4. **登录前查出口。** 在同一个浏览器里打开 `https://ipinfo.io/json`，`country` 应是你所在的国家，`org` 应是一家宽带运营商。命令行可以这样查：

   ```bash
   curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   这里的 USER、PASS、HOST、PORT 是占位符。
5. **以后一直用它。** 到期前续费，可以按 IP 开自动续费。IP 过期后会被收回，再买拿到的是另一个地址。
6. **Claude Code 用 HTTP。** 它读标准代理环境变量，不支持 SOCKS。设置方法见 [Claude 桌面版和 Claude Code 怎么设置代理](../claude-desktop-proxy-zh/README.md)。

## 账号被封以后

- **走官方申诉。** 按帮助中心《Safeguards warnings and appeals》的说法，用被封的账号登录 claude.ai，填写页面上的申诉表；不登录看不到这张表。
- **换 IP 解不了封。** 处罚针对的是账号和使用行为，不是网络地址。
- **不要另开新号。** 换一个 IP 重新注册，属于绕开处罚，和原来的问题叠在一起只会更糟。

## 常见做法和问题

| 做法 | 问题出在哪 |
|---|---|
| 封号后换个 IP 重新注册 | 绕开处罚，IP 不改变政策 |
| 人不在支持地区，挑一个支持国家的 IP | 政策看人实际所在地，这样用不被允许 |
| 家里宽带、手机流量、固定 IP 轮着用 | 同一个账号的登录地点来回跳 |
| 用公共的全局网络工具出口登录 | 一个出口背后有很多陌生人，记录不归你管 |
| 团队几个人共用一个账号 | 违反服务条款，每人应有自己的账号 |

## 常见问题

**换成住宅 IP 就不会被封了吗？** 不会。表里大部分原因和 IP 无关，Proxy302 也不承诺账号永不受限。

**在支持地区之间出差怎么办？** 政策看的是你人在哪里，目的地也在支持列表上即可。出差时继续用常驻地那个固定 IP，比到了一个国家换一个 IP 更稳定。

**团队要怎么配？** 每人一个账号、一个 IP。Claude 企业版可以按 IP 白名单限制访问，给每个远程成员一个固定 IP，管理员就有地址可加。名单由你们公司自己的管理员添加；Proxy302 不替你登记，和 Anthropic 没有对接，我们的 IP 不在任何白名单里，也不能让账号免去身份或手机验证。

**普通静态 IP 也行吗？** 也行，都是租期内不变的地址。AI 订阅 ISP 是按 AI 服务挑选的专用原生 ISP IP；普通静态 ISP 30 天 US$7.99，更便宜。
