# 静态住宅 IP 价格：按天、按月怎么算？

静态住宅（ISP）IP 按「个数 × 租期」计价，租期越长，单日价越低。以 Proxy302 为例：1 天 US$0.50，30 天 US$7.99，90 天 US$23.97，每个 IP，所有国家同价，1 PTC = 1 美元。这篇由 Proxy302 维护，我们卖这类 IP。适合要长期固定出口、想先算清预算的人。没有免费试用。

## 怎么算预算

总价 = 单价 × IP 个数。例如 10 个账号、每个 30 天：10 × US$7.99 = US$79.90。一单 1 到 100 个，国家不同不加价。

## 按天还是按月：判断方法

1. **要不要长期登录同一个账号？** 要，就买 30 天及以上，并开自动续费。
2. **只是测试？** 买 1 天，US$0.50，拿它做检查，再决定。
3. **只看公开页面、不登录？** 动态住宅按 GB 更省，不用买 IP。
4. **账号很多？** 按账号数买，一个账号一个 IP。

## 容易漏算的钱

- 过期的 IP 会被收回，续费晚了会换成另一个地址，账号要重新适应。到期前续费，才能保留同一个 IP。
- 协议在下单时就选好，一个 IP 只有一种，选错了要重新买。
- 一个账号一个 IP，每个账号各买一个，所以预算要按账号数乘。

## 什么时候不用买静态

如果你的工作不需要登录，只是抓公开页面、查价格、看广告，按 GB 的动态住宅通常更划算：普通线 US$1.50/GB，预付流量不过期，还可以保持会话。静态的价值在于「同一个账号反复从同一个地址登录」，没有这个需求，就不必为固定地址付租金。

## 买之前先检查

买到之后做四件事：在 WHOIS 查登记方；在两三个 IP 库里对比类型；查反向解析与黑名单；`curl -x http://USER:PASS@HOST:PORT https://ipinfo.io/json` 看 `country` 和 `org`（SOCKS5 用 `socks5h://`）。

## 一个小例子

假设你要运营 5 个账号，打算用满一个季度。每个账号买 90 天，一共 5 × US$23.97 = US$119.85。如果你不确定会不会长期做，可以先每个账号买 7 天（5 × US$3.50 = US$17.50）看效果，再续成 30 天。时间越不确定，越应该用短租期，但到期前别忘了续费，不然 IP 会被收回。

## 对照动态住宅算一笔账

30 天一个静态 IP 是 US$7.99，折成动态住宅普通线（US$1.50/GB）约 5.3 GB。你一个月跑的流量如果远小于 5 GB，又不用登录，按 GB 更省；需要固定出口，就不用比这个数。
