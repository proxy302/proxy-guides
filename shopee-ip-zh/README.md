# Shopee 多店铺用什么 IP

每家店（每个卖家账号）配一个静态 ISP IP，长期不换，只放在这家店专用的浏览器环境里；看前台价格、搜索排名这类不登录的事，用动态住宅按流量买。一家店今天一个地址、明天一个地址，或者几家店挤在同一个出口，登录记录都会乱。Proxy302 的静态 ISP 1 天 0.5 美元、30 天 7.99 美元，所有国家同价，30 天及以上的静态 IP 是你独享的；动态住宅 1.5 美元/GB 起。本指南由 Proxy302 维护，我们也卖这些代理。能开几家店、要交什么资料、怎么审核，以 Shopee 卖家中心对你所在站点的规定为准，IP 改变不了这些规则，也替代不了平台的审核。

## 先把规则弄清楚

Shopee 按站点运营，各站点、本土店和跨境店的入驻要求不一样。我们没有在 Shopee 官方帮助页上查到「一个卖家最多开几家店」的统一说法，所以这里不写数字：开店数量、资料要求，看卖家中心的说明，或者问你的招商经理。

查得到的一条和设备有关：Shopee 新加坡帮助中心写明，同一个账号可以在多台设备上登录；在新设备上登录后有 12 小时的冷静期，这期间不能改手机号或邮箱、不能给 ShopeePay 添加银行账户等（[原文](https://help.shopee.sg/portal/4/article/76624-[My-Account]-Can-I-log-in-to-the-same-Shopee-account-on-multiple-devices)）。可见换设备登录本身就会带来一段受限时间，固定环境、少折腾，日常操作会顺很多。

## IP 放在哪个国家

先想清楚你在 Shopee 那边登记的是什么身份：

- **本土店：** 选你公司或本人实际所在的国家，长期不变。
- **跨境店：** Shopee 知道你是跨境卖家。IP 放哪个国家，先看卖家中心的说明或问招商经理，按他们说的来；不要为了让店铺看起来像本地卖家去挑 IP。

不管哪种，定了就别来回换。

## 怎么配

1. **列清单。** 每家店一行：店铺名、站点、登录邮箱、对应的 IP、浏览器环境、IP 到期日。
2. **一家店买一个静态 IP。** 协议下单时选：放进指纹浏览器环境多用 SOCKS5；工具只支持 HTTP 就选 HTTP。
3. **一家店一个浏览器环境。** 在环境的代理设置里选和购买时相同的协议，填主机、端口、账号、密码，只填这一个环境。
4. **先验出口再登录。** 环境里打开 `https://ipinfo.io/json`，国家要对；也可以在电脑上用命令查：

   ```bash
   curl -sS --max-time 20 -x "socks5h://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   HTTP 的 IP 把 `socks5h://` 换成 `http://`。USER、PASS、HOST、PORT 是占位符。
5. **登录，固定下来。** 这家店以后只从这个环境、这个 IP 登录。
6. **员工各用各的登录。** 主账号密码不要在群里传来传去。
7. **按 IP 开自动续费。** 到期没续，IP 会被收回，再买拿到的是新地址；见[静态 IP 到期了还能继续用原来那个地址吗](../static-ip-expiry-renew-zh/README.md)。

## 平台要求验证时

如实提交营业执照、身份、收款这些资料，和你入驻时填的一致。IP 和这一步没有关系，帮不了资料不真实的申请。店铺被处罚，走卖家中心的申诉渠道；另开新店接着卖，解决不了问题。

## 常见问题排查

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 老是提示新设备登录 | 环境有时没走代理，或在别的电脑上直接登录 | 只从固定环境登录 |
| 环境的代理检测失败 | 协议选错（HTTP/SOCKS5），或字段填错 | 对照购买时的协议重填 |
| 报 407 | 账号密码不对 | 从「我的资产」重新复制 |
| 上个月好好的，今天连不上 | IP 到期被收回了 | 提前续费或开自动续费 |
| 查到的是机房公司 | 买成了机房 IP | 登录店铺换静态 ISP |
| 两家店查出同一个 IP | 有人把一个环境的代理复制到另一个环境 | 一家店一个 IP |

## 常见问题

**几家店能共用一个 IP 吗？** 不建议。一家店一个 IP，登录记录清楚，出问题也好排查。

**动态住宅能登录店铺吗？** 不适合。地址一直在变，登录店铺要用静态的。

**同一个国家的几个 IP 要挑不同城市吗？** 不需要刻意挑，国家对、长期固定更重要。

**有免费试用吗？** 没有。最小的购买是 1 个静态 IP 用 1 天，0.5 美元，可以先拿它把流程走一遍。
