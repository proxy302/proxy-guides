# 代理 IP 被网站标记、频繁弹验证或被拒，先查哪几项

先分清是 IP 的问题还是账号和操作的问题：用这个 IP、不登录任何账号，打开同一个网站的首页。不登录也被拦，多半是 IP 本身（类型、所在地、过往记录）让网站不放心；不登录正常、一登录就出事，问题多半在账号或操作上，换 IP 解决不了。然后依次查五项：IP 类型、出口国家和账号是否一致、IP 最近有没有变过、一个 IP 上是不是挂了多个账号、电脑上有没有别的代理或其他全局网络工具叠在一起。网站要求验证时，如实完成；代理不能代替验证，也不是绕开平台规则的办法。

*本指南由 Proxy302 维护，我们也销售文中提到的代理。*

## 第一步：是 IP 还是账号

| 测试 | 结果 | 说明 |
|---|---|---|
| 用这个 IP，不登录，打开网站首页和几个普通页面 | 也被拦、要验证、403 | 网站对这个地址或这类地址有限制 |
| 同上 | 正常 | IP 本身多半没问题，看账号和操作 |
| 用同一个 IP 打开别的大网站 | 也异常 | 可能是代理连接本身的问题，先排查网络 |

浏览器测试用一个干净的配置（新的浏览器配置文件或指纹浏览器里新建的环境），避免旧 Cookie 干扰判断。命令行可以这样看出口信息：

```bash
curl -sS -x http://USER:PASS@HOST:PORT https://ipinfo.io/json
```

## 第二步：IP 本身查五项

| 检查项 | 怎么查 | 不对时怎么办 |
|---|---|---|
| IP 类型 | 看返回里的 `org`：是宽带运营商还是云服务、机房公司。方法见 [怎么判断住宅、ISP 还是机房](../residential-or-datacenter-ip-check-zh/README.md) | 网站对机房地址不放心时，登录类账号改用静态住宅（ISP）IP |
| 国家、城市 | 和账号注册地、平时使用地对得上吗；不一致的处理见 [IP 所在地和购买的不一样](../proxy-ip-location-mismatch-zh/README.md) | 选和账号所在市场一致的国家 |
| 最近有没有变 | 动态住宅每个新连接可能换出口；静态 IP 到期会被释放，重买拿到的是新地址 | 登录类账号用静态 IP，开自动续费 |
| 一个 IP 挂了几个账号 | 自己数一数：同一个 IP 上登录了几个同平台账号 | 一个账号一个 IP、一个浏览器环境 |
| 有没有叠加 | 系统代理、其他全局网络工具、浏览器插件是否同时开着 | 只留一层；关掉其他工具后重测出口 |

## 第三步：看自己的操作

网站风控看的不只是 IP。下面这些和 IP 无关，换 IP 也会继续触发：

- 短时间内大量重复动作：批量关注、批量发帖、高频刷新、并发下单。
- 程序自动操作，而平台条款不允许。
- 账号资料、支付信息和使用地长期对不上。
- 刚登录就修改密码、绑定信息等敏感操作。

把节奏放慢、按平台规则使用，比换多少个 IP 都有用。

## 处理办法

| 情况 | 建议 |
|---|---|
| 不登录也被拦，且是刚买的 IP | 把测试结果（出口信息、被拦的页面）发给服务商，询问能否更换 |
| 不登录正常，账号被要求验证 | 如实完成验证；代理不能替代验证 |
| 账号被限制或封禁 | 走平台的申诉流程；换 IP 不能解除平台的处罚 |
| 只有某个网站拦，且网站明确不接受代理访问 | 尊重网站规定，改用它的官方接口或其他合规渠道 |

## 常见问题

**能不能先买一个便宜的 IP 测？** 可以。Proxy302 没有免费试用，最便宜的测试是一个静态 IP 用 1 天，0.5 美元。

**换了新 IP，账号会不会更危险？** 登录中的账号频繁换地址，本身就容易触发验证。换就换到同一个国家，换完遇到验证如实完成，之后固定用这个 IP。

**被标记的 IP 过一段时间会恢复吗？** 取决于网站，没法保证。与其等，不如先按上面的步骤确认问题出在哪。

**静态住宅和动态住宅，哪个更不容易出问题？** 要长期登录的账号用静态住宅（ISP）IP，地址固定；不登录的采集、查价用动态住宅更合适。区别见 [静态住宅和动态住宅 IP 的区别](../static-vs-dynamic-residential-ip-zh/README.md)。
