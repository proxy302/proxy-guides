# 跨境电商 IP 怎么选？

跨境电商要登录店铺后台、管多个账号，应该选静态 ISP（静态住宅）IP，一个店铺一个 IP；只是看价格、查竞品、抓公开页面，选按 GB 计费的动态住宅就够了。这篇由 Proxy302 维护，我们卖这类 IP。静态 ISP 1 天 US$0.50，30 天 US$7.99；亚马逊专用 ISP 30 天 12 PTC（1 PTC = 1 美元），首个 IP 半价。没有免费试用。

## 先问：这个 IP 要做什么

| 你要做的事 | 推荐类型 | Proxy302 参考价 |
|---|---|---|
| 登录店铺后台，长期管理一个店铺 | 静态 ISP | 30 天 US$7.99 / 个 |
| 亚马逊店铺 | 亚马逊专用 ISP | 30 天 12 PTC，首个 IP 半价 |

| 对接受服务器地址的网站跑大流量 | 数据中心 | 动态 US$0.40/GB；静态 30 天 US$3.99 |

数据中心 IP 能被网站认出是服务器地址，不要拿来登录店铺。

## 为什么登录店铺要用静态

店铺后台看的是「这个账号平时从哪里登录」。如果每次连接地址都变，同一个账号一会儿在这、一会儿在那。静态 ISP 在整个租期里是同一个地址，登记在运营商名下，你的账号有一个稳定的出口。

注意：它只是稳定的网络出口，不会改变平台规则。平台要求验证资料或身份时，如实完成，IP 在这件事上帮不了你。

## 选购清单

1. **国家和店铺站点一致。** 美国站店铺买美国 IP。所有国家价格相同，选对国家不会多花钱。
2. **一个店铺一个 IP。** 每个店铺、每个账号都买各自的 IP，并标注清楚对应关系。
3. **协议。** HTTP 或 SOCKS5，下单时二选一，一个 IP 只有一种。配指纹浏览器环境多选 SOCKS5。
4. **先买短租期。** 1 天 US$0.50，用这天时间做检测，再买 30 天。
5. **交付前有没有检测。** 亚马逊专用 ISP 在交付前检测，确认不是机房地址。其他店铺平台，自己用下面的方法查。
6. **续费方式。** 到期前续费保留同一个 IP，也可以按 IP 开自动续费。过期的 IP 会被收回。

## 自己动手检测

- 在 ARIN、RIPE 或 APNIC 的 WHOIS 查地址段，登记方应是运营商。
- 在两三个 IP 库里对比类型栏，应是 isp 或 residential。
- 跑 `curl -x http://USER:PASS@HOST:PORT https://ipinfo.io/json`，看 `country` 和 `org`（SOCKS5 用 `socks5h://`）。
- 再查反向解析和黑名单。

## 店铺账号卫生

- 一个账号一个 IP，一个账号一个浏览器环境。
- 这个号一直用这个 IP，不要换来换去。
- 到期前续费，不要等过期。
- 环境里不要再开别的全局网络工具。
- 配好之后，在窗口里打开查 IP 的网页，确认出口再登录。

## 多店铺的记录方式

店铺多了以后，建议在表格里一行记一个店铺：店铺名、站点国家、对应的 IP 备注、协议、到期日、是否开了自动续费。每次续费或换号前先看这张表。这样不会出现一个 IP 同时挂在两个店铺上，也不会有 IP 因为没人记得到期日而过期。

## 常见问题

**店铺很多，是不是 IP 买得越多越好？** 按账号数买，一个账号一个，不用多买。一单可买 1 到 100 个。

**动态住宅能登录店铺吗？** 不推荐。每个连接换地址，账号登录出口不稳定；如果必须用，选能保持会话的线路。

**30 天的 IP 是独享的吗？** 30 天及以上的静态 IP 是你独享的。

**亚马逊店铺该选哪个？** 看 [亚马逊专用 ISP](https://proxy302.com/zh/proxies/amazon-isp/) 和[亚马逊场景页](https://proxy302.com/zh/use-cases/cross-border-ecommerce/amazon/)。想了解 ISP 代理是什么，看[ISP 代理和住宅代理的区别](../isp-proxy-vs-residential-proxy/README.zh-CN.md)。
