# 在日本经营乐天市场（Rakuten Ichiba）店铺，后台登录用什么 IP？

一家店配一个日本的静态 ISP（静态住宅）IP，整个经营期间不换，只放在这家店专用的浏览器配置里；店员各用各的登录账号，不共用店主账号。不登录的事，比如看乐天站内搜索排名、别家的价格，用日本的动态住宅按流量买。本指南由 Proxy302 维护，我们也销售这些代理：日本静态 ISP 1 天 0.5 美元、30 天 7.99 美元，所有国家同价；30 天及以上的静态 IP 由买家独享；动态住宅 1.5 美元/GB 起。谁能在乐天开店、要交哪些资料、怎么审核，以乐天官方的出店说明为准，IP 改变不了这些，也代替不了审核。

## 适合谁

店铺主体在日本、团队在几个地方办公的卖家：公司办公室、员工家里的宽带、出差用的笔记本、云桌面。每个地方的出口地址都不一样，店铺后台天天看到新网络来登录。把日常运营集中在一个固定 IP 的浏览器配置里，后台看到的就是同一个出口；谁做了什么，用各自的登录账号区分。

这不是让店铺"看起来像别人"的办法。一家店、一个经营主体、它自己的员工。

## 怎么配

1. **一家店买一个日本静态 ISP。** 协议下单时选定，一个 IP 只有一种：用浏览器扩展或系统代理选 HTTP，放进指纹浏览器配置多用 SOCKS5。
2. **给这家店单独建一个浏览器配置**（Chrome、Edge 的个人资料，或指纹浏览器里的一个环境），只用来开这家店的后台。
3. **在这个配置的代理设置里填主机、端口、账号、密码**，协议和下单时一致。
4. **登录前先验出口。** 在这个配置里打开 `https://ipinfo.io/json`，`country` 应该是 `JP`。也可以在终端查：

   ```bash
   curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   USER、PASS、HOST、PORT 是占位符；SOCKS5 的 IP 把 `http://` 换成 `socks5h://`。
5. **各人用各自的账号登录。** 后台如果支持给员工单独开账号，就别把店主的账号密码在群里传。
6. **按 IP 打开自动续费。** 到期没续，IP 会被收回，再买拿到的是新地址。
7. **记一张表：** 店铺、IP、浏览器配置名、谁有权限、续费日期。

## 平台要求验证或审核时

如实提交和出店时一致的公司资料、负责人信息、收款信息。IP 和这一步无关，帮不了资料不真实的申请。店铺被要求整改或受限，走乐天的官方联系渠道处理，不要换个新店接着做。

## 日常要注意

- 一家店、一个 IP、一个浏览器配置，不把一个配置的代理复制到另一个配置。
- 浏览器底下不要再开其他全局网络工具，只保留一层代理。
- 同一家店不要一会儿走固定 IP、一会儿走家里宽带直连。
- 员工离职，当天停他的后台账号；固定 IP 不用换。

## 常见问题排查

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 浏览器配置的代理检测不通过 | 协议选错（HTTP 和 SOCKS5 搞反） | 按下单时的协议重填 |
| 一直弹账号密码框，或报 407 | 代理账号密码不对 | 从订单页重新复制 |
| 查到的国家不是 JP | 配置没走代理，或上面还叠了别的网络工具 | 关掉其他工具，重新检查代理设置 |
| 上个月好好的，今天连不上 | IP 到期被收回 | 提前续费，或开自动续费 |
| 后台频繁提示新环境登录 | 有人在固定配置以外登录 | 约定这家店只在固定配置里打开 |

## 常见问题

**IP 要挑日本哪个城市？** 国家对最要紧。购买页能选城市的话，选公司所在的地区就行，选定以后别换。

**两家店能共用一个 IP 吗？** 不建议。一家店一个 IP，各自的登录记录清楚，出问题也好查。

**员工在家办公，也要走这个 IP 吗？** 处理这家店后台的时候走，在那个固定的浏览器配置里打开就行；平时上网、处理别的事不需要。

**有免费试用吗？** 没有。最小的购买是 1 个静态 IP 用 1 天，0.5 美元。
