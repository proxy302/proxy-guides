# 怎么判断一个 IP 是住宅、ISP 还是机房？

看这个 IP 登记在哪个自治系统（ASN）、哪家公司名下：登记在家庭宽带或移动运营商名下的，属于住宅或 ISP 类地址；登记在云计算、主机托管公司名下的，就是机房地址。实际操作是三步交叉看：ipinfo 的 `org` 字段、IP2Location 的「使用类型」、反向 DNS 的主机名。住宅和静态 ISP 在数据库里通常长得一样，要分清它俩，得隔一段时间连续测几次，看地址变不变。

*本文由 Proxy302 维护，我们出售住宅、静态 ISP 和机房三类代理 IP。*

## 三类地址各有什么特征

| | 动态住宅 | 静态 ISP（静态住宅） | 机房 |
|---|---|---|---|
| ASN 登记在谁名下 | 宽带或移动运营商 | 宽带运营商 | 云服务、主机托管公司 |
| IP2Location 使用类型 | 多为 ISP，移动网络为 MOB | 多为 ISP | 多为 DCH |
| 反向 DNS 主机名 | 常带运营商域名 | 有的有，有的没有 | 常带云厂商域名，或没有记录 |
| 地址会不会变 | 按连接或会话变 | 租期内固定 | 静态机房固定，动态机房会变 |

## 第一步：查 ASN 和登记的组织

把 `IP` 换成你要查的地址：

```bash
curl -s https://ipinfo.io/IP/json
```

返回里的 `org` 形如「AS 号 + 公司名」。拿公司名搜一下，它是家庭宽带、手机运营商，还是做云服务器、托管业务的公司，答案基本就出来了。返回里如果有 `hostname`，那是反向 DNS，下面第三步会用到。

要查「我现在通过代理出去是什么地址」，就让请求走代理：

```bash
curl -s -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
```

## 第二步：看数据库给的使用类型

IP2Location 的查询页会给出 Usage Type（使用类型）。常见代码：

- **ISP**：固定宽带运营商
- **MOB**：移动运营商
- **DCH**：数据中心、主机托管、网络转接
- **COM / ORG / EDU / GOV**：商业公司、机构、学校、政府

各家数据库分类方法不同，同一个 IP 可能在甲库里是 ISP、在乙库里是 hosting。不要只信一家，把两三家的结果和第一步的 ASN 放在一起看，以多数为准。

## 第三步：反向 DNS 和 whois

```bash
dig -x IP +short
whois IP | grep -iE "netname|orgname|org-name|descr|country"
```

Windows 可以用 `nslookup IP` 查反向记录。主机名里出现云厂商、服务器、托管一类字样，基本是机房；出现宽带、拨号相关的命名（例如带 `dsl`、`cable`、`dynamic`），多半是住宅。没有反向记录说明不了什么，很多地址本来就没设。

## 第四步：分清动态住宅和静态 ISP

数据库一般分不出这两种，因为都登记在运营商名下。真正的区别是地址固不固定，隔 30 秒测一次，连测五次：

```bash
for i in 1 2 3 4 5; do
  curl -s -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/ip; echo
  sleep 30
done
```

五次都是同一个地址，是固定 IP；隔一会儿就换，是动态住宅（没开粘性会话的情况下）。粘性会话的用法见[这篇](../sticky-session-zh/README.md)。

## 常见误判

| 现象 | 怎么理解 |
|---|---|
| 同一个 IP，一家库说住宅，一家说机房 | 各库更新时间和分类口径不同，结合 ASN 看多数 |
| 城市和购买时选的不一样 | 城市级定位误差很常见，以国家为准 |
| 查出来是自己家的宽带地址 | 请求没走代理，回头检查代理设置 |
| `org` 是个没听过的小公司 | 可能是地方运营商或企业网络，搜这个 ASN 的官网再判断 |
| 上周查是 ISP，这周变成 hosting | 数据库改了分类；有疑问可以向该数据库提交更正 |

## 常见问题

**网站是怎么判断地址类型的？** 多数网站也是查这类商业 IP 数据库，再加上自己的规则。具体哪家网站用哪家库，外人无从得知，所以只能多库交叉。

**机房 IP 就一定不能用吗？** 不是。调接口、做监控、访问不区分地址类型的网站，机房 IP 便宜又够用。怎么取舍见 [Datacenter vs residential proxy](../datacenter-vs-residential-proxy/README.md)。

**买到的 ISP IP 被查成机房怎么办？** 先用两三家库交叉确认。如果多数都显示机房，带着查询截图联系卖家。

**手机网络的 IP 算住宅吗？** 习惯上单列为移动 IP，数据库里标 MOB。它也登记在运营商名下，但地址的分配方式和家庭宽带不同，一般分开看待。
