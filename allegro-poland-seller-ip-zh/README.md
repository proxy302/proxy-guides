# 在波兰经营 Allegro 店铺，卖家后台用什么 IP 登录？

一个 Allegro 卖家账号配一个波兰的静态 ISP（静态住宅）IP，店铺开多久就用多久，只放在这个账号专用的浏览器配置里；员工通过 Allegro 企业账号自带的授权功能各自登录，不传店主密码。不登录的事，比如看 allegro.pl 上的搜索排名、同行价格，用动态住宅按流量买。本指南由 Proxy302 维护，我们也销售这些代理：波兰静态 ISP 1 天 0.5 美元、30 天 7.99 美元，所有国家同价，30 天及以上的静态 IP 由买家独享。谁能在 Allegro 开店、要交哪些公司和收款资料、怎么审核，都以 Allegro 官方规则为准，IP 改变不了这些。

## 适合哪种卖家

经营主体和仓库在波兰、日常操作分散在几个地方的团队：办公室宽带、员工家里的网络、手机热点、出差的笔记本。每换一个地方，后台看到的就是一个新出口。把店铺后台集中到一个固定波兰 IP 的浏览器配置里，账号这一侧只看到一个稳定的地址；谁改了商品、谁回了买家，靠每个人自己的登录区分。

IP 的国家要跟经营主体实际所在的国家一致。公司注册、经营都不在波兰，就用公司所在国的 IP，不要拿波兰 IP 把店铺装成本地卖家。

## 先用好 Allegro 自己的权限功能

Allegro 的企业账号（Konto Firma）可以把账号的部分权限授给其他人，员工用自己的 Allegro 账号登录后切换到公司账号操作，不需要知道店主密码。入口在账号设置的「Uprawnienia」（权限）相关页面，菜单名称会随版本调整，具体以 [Allegro 帮助中心](https://help.allegro.com/) 为准。

几条经验：

- 店主账号的密码和二次验证只留在负责人手里。
- 按岗位授权：处理订单的不一定要能改价格，看报表的不一定要能发货。
- 员工离职当天收回权限；固定 IP 不用跟着换。

## 配置步骤

1. **一个卖家账号买一个波兰静态 ISP。** 协议下单时选定，之后不能换：浏览器扩展、系统代理用 HTTP；指纹浏览器环境多用 SOCKS5。
2. **给这个账号单独建一个浏览器配置**（Chrome 或 Edge 的个人资料，或者指纹浏览器里的一个环境），只开这一家的后台。
3. **在这个配置的代理设置里填主机、端口、用户名、密码**，协议跟订单页一致。
4. **登录前先看出口。** 在这个配置里打开 `https://ipinfo.io/json`，`country` 应该是 `PL`。终端里也可以查：

   ```bash
   curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   USER、PASS、HOST、PORT 换成订单页上的信息；SOCKS5 的 IP 把 `http://` 换成 `socks5h://`。
5. **店主登录一次，再给员工开权限。** 员工在这个配置里用自己的账号登录。
6. **按 IP 打开自动续费。** 到期没续的 IP 会被释放，再买到的是新地址。
7. **记一行台账：** 账号、IP、浏览器配置名、谁有哪些权限、续费日期。

## Allegro 要求验证或审核时

按开户时填的公司信息、负责人信息、收款账户如实提交。IP 跟这一步没有关系，也帮不了资料不真实的申请。账号被限制，走 Allegro 的官方申诉和客服渠道，不要另开新号接着卖。

## 常见问题排查

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| ipinfo 显示的国家不是 PL | 浏览器配置没走代理，或者上面又叠了其他全局网络工具 | 关掉其他工具，重新检查代理设置 |
| 指纹浏览器的代理检测不通过 | HTTP 和 SOCKS5 选反了 | 按订单页上的协议重填 |
| 报 407 或反复弹密码框 | 代理用户名或密码不对 | 从订单页重新复制 |
| 员工频繁收到新设备登录提醒 | 有人在这个配置以外登录 | 约定店铺后台只在这个配置里打开 |
| 上个月正常，今天连不上 | IP 到期被释放 | 提前续费，或打开自动续费 |

## 常见问题

**要选波兰哪个城市？** 国家最要紧。购买页可以选城市的话，选离公司或仓库近的，选定就别换。

**两个 Allegro 账号能共用一个 IP 吗？** 一个账号一个 IP，登录记录互不混在一起，出问题也好查。

**员工用手机上的 Allegro 应用也要走代理吗？** 不一定。每个人用自己的账号、在自己手机上登录，是正常使用。固定 IP 主要管电脑上那个天天处理后台的浏览器配置。

**有免费试用吗？** 没有。最便宜的测试是 1 个静态 IP 用 1 天，0.5 美元。
