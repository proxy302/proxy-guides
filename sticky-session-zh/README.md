# 动态住宅 IP 的粘性会话是什么，怎么用？

粘性会话（sticky session）是让动态住宅代理在一段时间里保持同一个出口 IP 的设置。不开的时候，每个新连接都可能换一个地址；开了之后，带同一个会话标识的请求都从同一个地址出去，直到会话到期或者你换了标识。用法是在代理用户名里带上服务商文档规定的会话参数，Proxy302 的控制台会把带会话参数的连接信息直接生成好。

*本文由 Proxy302 维护，我们出售文中提到的动态住宅和静态 IP。*

## 轮换、粘性会话、静态 IP 怎么选

| | 轮换（不开粘性） | 粘性会话 | 静态 ISP |
|---|---|---|---|
| 出口地址 | 新连接可能换一个 | 会话有效期内不变 | 整个租期不变 |
| 适合的活 | 大量互不相关的请求，比如批量查公开价格 | 要连着走几步的流程，比如翻页、加购物车看运费 | 长期登录的账号 |
| 计费方式 | 按流量 | 按流量 | 按 IP 和天数 |

判断方法很简单：如果中途换地址会让这件事做不下去，就需要粘性会话；如果要连续几天、几周用同一个地址，粘性会话不够，直接买静态 ISP。

## 设置步骤

1. 在 Proxy302 控制台的动态住宅里生成需要保持会话的连接信息，会话参数由控制台生成，不用自己拼。
2. 复制生成的主机、端口、用户名、密码。会话参数已经写在用户名里，不要手动删改，也别让软件截断过长的用户名。
3. 一个任务用一个会话标识。两个任务用了同一个标识，它们就会走同一个出口。
4. 想换地址时，在控制台重新生成一份连接信息即可。会话能保持多长时间，以控制台的说明为准。

各家服务商的会话参数写法不同，换服务商时要看对方的文档，不能照搬。

## 代码：让一串请求走同一个出口

保持出口不变有两个办法，作用范围不同：

- **会话参数**：写在用户名里，即使连接断了重连，在有效期内还是同一个出口。
- **连接复用（keep-alive）**：同一条连接上的请求本来就走同一个出口，哪怕没开粘性会话。但连接一断，重建后就可能换地址。

Python 里用 `requests.Session` 能同时用上两者：

```python
import requests

PROXY = "http://USER:PASS@HOST:PORT"  # USER 用控制台生成的、带会话参数的用户名

with requests.Session() as s:
    s.proxies = {"http": PROXY, "https": PROXY}
    for step in range(3):
        ip = s.get("https://ipinfo.io/ip", timeout=20).text.strip()
        print(step, ip)
```

作为对照，下面这种写法每次都新建连接，如果用户名里没有会话参数，三次打印出的地址很可能各不相同：

```python
import requests

PROXY = "http://USER:PASS@HOST:PORT"
for step in range(3):
    r = requests.get("https://ipinfo.io/ip", proxies={"http": PROXY, "https": PROXY}, timeout=20)
    print(step, r.text.strip())
```

**用浏览器时尤其要开粘性会话。** 浏览器打开一个页面会同时建很多条连接去加载图片、脚本，如果是轮换模式，同一个页面的资源可能从好几个地址加载。用 Playwright 等工具接动态住宅时，把带会话参数的用户名填进 `proxy.username` 即可。

## 常见错误

| 现象 | 原因 |
|---|---|
| 开了粘性会话，IP 还是变了 | 会话到期；或用户名里的会话参数被改动、被软件截断 |
| 两个任务拿到同一个出口 | 用了同一个会话标识，给每个任务单独生成 |
| 流程走到一半掉线、要求重新登录 | 用的是轮换模式，或会话已到期；长期登录请换静态 ISP |
| 加了会话参数后报 407 | 用户名拼错，和密码对不上；直接从控制台重新复制 |
| 流量用得比预想快 | 浏览器在加载图片和视频；脚本里可以拦掉不需要的资源 |

## 常见问题

**粘性会话能保持多久？** 以控制台和服务商文档为准。需要几天以上的固定地址，用静态 ISP 更合适，1 天起租。

**会话到期后一定会换 IP 吗？** 不一定，可能换，也可能碰巧还是同一个。程序里不要依赖「到期后一定换」或「到期后一定不换」。

**能用粘性会话登录账号吗？** 短流程可以。要长期保持登录的账号，会话总会到期，地址一变就前后对不上，这种情况用静态 ISP。

**预付的流量会过期吗？** Proxy302 的动态住宅预付流量不过期。
