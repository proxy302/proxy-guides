# 做 Zalando 合作伙伴（Partner Program），zDirect 后台用什么 IP 登录？

运营团队在德国的品牌或零售商，给 zDirect 后台配一个德国静态 ISP（静态住宅）IP，长期不换，只在专门打开 zDirect 的那个浏览器配置里用；同事由管理员在 zDirect 的用户管理里各开一个账号，用自己的邮箱登录，不共用管理员密码。只是去 zalando.de 前台看商品展示和同类价格，用动态住宅按流量买就行。本指南由 Proxy302 维护，我们也销售这些代理：德国静态 ISP 1 天 0.5 美元、30 天 7.99 美元，所有国家同价，30 天及以上的静态 IP 由买家独享。能不能加入合作伙伴计划、要交什么资料、审核怎么走，都由 Zalando 决定，IP 不改变这些。

## 固定 IP 管什么

zDirect 是 Zalando 给合作伙伴用的后台，商品、订单、库存和报表都在里面。一个品牌团队往往是几个人在几个地方打开它：办公室、仓库、在家、出差。固定一个德国 IP 的浏览器配置，后台看到的就是一个稳定的出口；谁做了什么，交给 zDirect 自己的用户和角色去区分。

国家跟着团队实际办公的地方走：团队在德国用德国 IP；团队在别的国家，就用那个国家的 IP（我们卖的国家见[支持国家列表](https://proxy302.com/zh/locations/)）。不要为了显得像德国本地商家去挑德国 IP。

## 先用 zDirect 的用户管理分人

按 Zalando 开发者文档里的[用户管理说明](https://developers.merchants.zalando.com/docs/dev-portal-users-management.html)（2026 年 11 月 27 日查看）：

| 项目 | 内容 |
|---|---|
| 谁能加人、改权限 | 只有 Administrator |
| 怎么加 | 在 User Management 点「Add User」，填邮箱，点「Confirm」，选角色，点「Apply」，核对后点「Add User」；对方收到邮件，按链接设置登录信息 |
| 角色 | Administrator：完整权限，可以创建、管理应用和合作伙伴；Developer：对应用、合作伙伴和用户只读 |
| 已有 zDirect 账号的人 | 加进来会成为 Connected user，名字改不了，角色可以改，也可以撤销 |

文档还提醒三件事：不要把不认识的人加进账号；不在团队里的人要及时撤销或删除，否则可能泄露数据；最好留不止一个 Administrator，保证总有人能管理用户、重置密码。

## 配置步骤

1. **买一个德国静态 ISP。** 协议下单时选定，一个 IP 只有一种：浏览器扩展、系统代理用 HTTP；指纹浏览器环境多用 SOCKS5。
2. **建一个只开 zDirect 的浏览器配置。** Chrome、Edge 的单独个人资料，或指纹浏览器里的一个环境都可以。
3. **填代理。** 主机、端口、用户名、密码照订单页填，协议要一致。
4. **登录前看出口。** 在这个配置里打开 `https://ipinfo.io/json`，`country` 应为 `DE`。终端里也可以查：

   ```bash
   curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json
   ```

   USER、PASS、HOST、PORT 是占位符；SOCKS5 的 IP 用 `socks5h://`。
5. **管理员登录，再给同事开账号。** 同事收到邮件设好登录信息后，也在这个配置里登录。
6. **打开这个 IP 的自动续费。** 到期不续会被释放，重新购买拿到的是别的地址。
7. **记台账：** 后台账号、IP、浏览器配置名、每个用户的角色、续费日期。

## Zalando 要求核验时

照申请时提交的公司信息、负责人和收款资料如实回复，走 Zalando 的官方渠道。代理只管网络出口，和核验无关，也帮不了资料不真实的申请。

## 出问题先看这里

| 现象 | 可能原因 | 处理 |
|---|---|---|
| ipinfo 显示的不是 DE | 浏览器配置没走代理，或叠了其他全局网络工具 | 只留一层代理，重新检查设置 |
| 代理检测失败 | HTTP 和 SOCKS5 填反了 | 按订单页的协议改 |
| 407 或反复弹认证框 | 代理用户名或密码错 | 从订单页重新复制 |
| 同事登录老要额外确认 | 有人在别的浏览器或网络里登录 | 约定后台只在这个配置里打开 |
| 昨天能用，今天连不上 | IP 到期被释放 | 提前续费或开自动续费 |

## 常见问题

**几个同事能同时用这个 IP 登 zDirect 吗？** 可以。他们是同一个合作伙伴账号下的不同用户，各用各的登录，出口是同一个 IP。

**团队一部分在德国、一部分在别的国家怎么办？** 各自用所在国家的 IP，或者约定后台只由德国的同事操作。别让人在外国的同事挂德国 IP。

**德国选哪个城市？** 国家对就行。购买页能选城市时，挑离办公室或仓库近的，选了就固定下来。

**有免费试用吗？** 没有。最小购买是 1 个静态 IP 用 1 天，0.5 美元。
