# TikTok 静态住宅 IP 怎么配置？

每个 TikTok 账号买一个静态 ISP IP，国家选该账号面向的市场。把它的主机、端口、用户名、密码填进这个账号专用的浏览器环境或手机，用 IP 回显页检查出口，然后再登录。此后这个账号一直用这个 IP。IP 只是让账号有稳定的连接，不改变 TikTok 的规则，也解除不了限制。

*由 Proxy302 维护。我们是服务商，不是中立评测方。[English](README.md)*

## 先读 TikTok 的条款

按我们的阅读，TikTok 服务条款（最近更新于 2025 年 12 月 1 日）里有两条和运营账号直接相关：你必须保密密码，并对账号下的所有行为负责；不得使用自动化脚本收集信息或以其他方式与服务交互。所以无论用什么 IP，账号都应由真人在 App、网页或经认可的工具里操作，密码不要共享。这两条与网络出口无关。

## 用静态还是动态？

判断很简单：同一个账号是否要反复从同一个出口登录？是，就用静态 IP。如果只是不登录地看公开内容，动态住宅更省钱。

| | 静态 ISP IP | 动态住宅 |
|---|---|---|
| 出口 | 整个租期固定 | 每个连接换新 IP，或在一次会话里保持 |
| 适合 | 长期从同一地点登录的单个账号 | 不登录，从不同国家看公开页面 |
| 位置 | 国家 | 国家，部分线路可到州或主要城市 |
| Proxy302 计费 | 按 IP 加租期 | 按 GB |

## 操作步骤

**1. 选国家。** 选账号面向的市场。面向美国观众的店铺或创作者账号，就选美国出口。选定后保持不变，不要为了测试来回换。某个国家能不能访问某个平台会随时间变化，Proxy302 公布了每小时一次的平台访问检查，可以先看看。

**2. 一个账号买一个 IP。** 在 Proxy302 控制台选「静态 ISP」，按 IP 加租期计费，选地区、租期和数量。截至我们最近一次核对 [proxy302.com/zh/pricing/](https://proxy302.com/zh/pricing/)：1 天 US$0.50，30 天 US$7.99，各国价格相同。最小购买是 1 个 IP 用 1 天。库存每天变化，能买哪些国家以下单页为准。

**3. 选协议。** HTTP 或 SOCKS5，购买时选定，每个 IP 只带一种协议。指纹浏览器环境一般选 SOCKS5；iPhone 的 Wi-Fi 代理和只支持 HTTP 的工具选 HTTP。

**4. 复制账密。** 打开「我的资产」，查看该 IP 的凭据，复制主机、端口、用户名、密码。给每个 IP 标上账号和市场，免得以后弄混。

**5. 放进一个环境或一部手机。**
- *浏览器环境：* 在指纹浏览器里每个账号建一个环境，代理类型选与 IP 一致的自定义代理（HTTP 或 SOCKS5），粘贴四项。见[指纹浏览器怎么配家宽 IP](../antidetect-browser-with-residential-ip/README.zh-CN.md)。
- *iPhone：* 设置，无线局域网，点网络旁的 (i)，配置代理，手动。填 HTTP IP 的服务器和端口，打开「鉴权」，填用户名和密码。它对 Safari 和遵循系统代理的 App 生效；不走系统代理的 App 不会用到。

**6. 登录前检查出口。** 通过代理访问 `https://ipinfo.io/json`。确认 `country` 是你买的国家，看 `org` 显示的网络。不同查询服务给出的城市可能不同，以国家为准。匹配之后再打开 TikTok。

```
curl -x socks5h://USER:PASS@HOST:PORT https://ipinfo.io/json
```

（HTTP 的 IP 用 `-x http://USER:PASS@HOST:PORT`。这里是占位符，不是真实账密。）

## 让账号保持稳定的习惯

- 一个账号、一个 IP、一个环境或一部手机。不要在同一个 IP 上登录两个账号。
- 每次都让账号保持在同一个国家。
- 手动操作，或通过经认可的工具发布。不要用脚本自动化。
- 不共享密码，只有负责人使用账号。
- 同一个账号不要在代理、其他全局网络工具和家里网络之间来回切换，只保留一层。
- 账号被限制时，按 TikTok 提供的申诉流程处理。IP 无法撤销处罚。

## 续费

静态 IP 在租期内不变。到期前续费通常能保留同一个 IP；过期的 IP 会被释放，超过到期日不能再续。自动续费是可以按 IP 在「我的资产」里开关的设置，所以下单时看勾选框，之后再看一次设置。如果某个 IP 不得不更换，会换成同一国家的另一个 IP，你需要更新环境里的配置。

## 排错

| 现象 | 检查 |
|---|---|
| 浏览器里代理检测失败 | 类型（HTTP 或 SOCKS5）要与 IP 一致；四项完整粘贴，主机栏不要带协议头 |
| 407 错误 | 用户名或密码缺失或错误；用这个 IP 自己的凭据 |
| 昨天能用今天不行 | 租期可能已结束，到「我的资产」看到期日 |
| TikTok 显示别的国家 | 环境没走代理，或上面还叠了其他全局网络工具 或第二层代理 |
