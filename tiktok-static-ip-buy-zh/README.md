# TikTok 静态 IP 怎么买？买之前要定的 5 件事

买 TikTok 静态 IP，下单前先定五件事：数量（一个账号一个 IP）、国家（账号面向的市场，定了就不换）、协议（看你的浏览器配置或手机支持 HTTP 还是 SOCKS5，买后不能改）、时长（试用买 1 天，长期运营买 30 天以上并开自动续费）、验收方法（拿到 IP 先查出口国家和网络归属，合格了再登录）。本文由 Proxy302 维护，我们出售文中提到的 IP：静态 ISP 每个 1 天 US$0.50、30 天 US$7.99，所有国家同价，适合给面向固定市场的账号配一个长期出口。IP 只负责连接稳定，不改变 TikTok 的规则。

## 五件事一览

| 要定的事 | 怎么定 | 定错了会怎样 |
|---|---|---|
| 数量 | 现有账号数，加上近期确定要开的号 | 少买就会有两个号挤一个 IP；多买是白付租金 |
| 国家 | 账号内容面向的市场 | 中途换国家，账号的登录地点就跳了 |
| 协议 | 你放 IP 的那个软件或设备支持什么 | 类型对不上，检测直接失败，只能重买 |
| 时长 | 先 1 天验收，再按运营周期续 | 买太长不合用浪费钱；买太短忘了续，IP 被收回 |
| 验收方法 | 下单前写好合格标准 | 没标准就容易「先用着」，出了问题分不清原因 |

## 第 1 件：数量

按账号算，不按设备、不按人算。三个人轮班管五个号，买五个。还没定下来的号先别囤 IP，等开号那天再买，免得租期空转。给每个 IP 起一个和账号对应的备注，比如「US-美妆-01」，以后续费、排错都靠它对号。

## 第 2 件：国家

选账号内容的目标观众所在的国家。面向美国观众，就买美国 IP。静态 ISP 各国同价，所以国家只按市场选，不用考虑价格。选好以后整个账号生命周期都保持不变；做第二个市场，就开第二个号、买第二个 IP，不要让一个号在两个国家之间切换。

## 第 3 件：协议

先看 IP 要放在哪：

| 放在哪 | 一般选 |
|---|---|
| 指纹浏览器的配置 | SOCKS5 或 HTTP 都可以，看软件的代理栏 |
| iPhone 的 Wi-Fi 代理设置 | HTTP（系统设置里可以填用户名和密码） |
| 用 Playwright、Puppeteer 驱动的 Chromium | HTTP，Chromium 不支持带账密的 SOCKS5 |

一个 IP 只有一种协议，下单时选定。同一批账号用同一种工具，就统一买一种协议，后面配置不容易乱。

第一个 IP 买 1 天做验收，合格后续成 30 天或更长。30 天及以上的静态 IP 为购买者独享。长期运营的号按 IP 打开自动续费；租期结束而没续的 IP 会被收回，再买拿到的是另一个地址。

## 第 5 件：验收方法

下单前就把合格标准写下来，拿到 IP 逐条对：

1. **出口国家。** `curl -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/country` 返回的两个字母要和下单国家一致（SOCKS5 用 `socks5h://`，命令里是占位符）。
2. **网络归属。** 把上面的 `country` 换成 `org`，返回的应是宽带运营商，不是云服务或托管公司。
3. **放进环境后再查一次。** 在指纹浏览器配置或手机里打开同一个查询页，结果要和命令行一致，再做一次 WebRTC 检测，不能出现本机地址。
4. **记下结果。** 验收日期、国家、归属写进备注，之后出问题有据可查。

全部通过再登录 TikTok。任何一条不对，先联系服务商处理，不要带着问题用。

## 常见错误

| 错误 | 后果 |
|---|---|
| 先登录，回头再查 IP | 万一出口不对，登录记录已经留下了 |
| 为了比价分几家各买一点 | 每家的协议、续费规则不同，管理变乱 |
| 一个号测几个国家「看哪个好」 | 账号在几个国家之间跳 |
| 只看下单页写的国家，不自己查 | 出口和预期不一致也发现不了 |
| 到期才想起续费 | IP 被收回，账号换了新地址 |
