# 原生 IP 和广播 IP 怎么区分，自己怎么查

「原生」「广播」是 IP 查询工具打的标签，没有统一标准，但意思大体一致：原生 IP 是三份记录说的是同一个国家——地址段在地区互联网注册机构的登记国、IPinfo 和 IP2Location 这类定位库显示的国家、广播这个地址段的网络（ASN）所在国；广播 IP 是登记在一个国家、却在另一个国家广播和定位，登记记录和实际位置对不上。要不要在意，看用途：长期固定在一个国家的账号、客户拿 ping0 这类工具验收，原生更省心；不登录、只看公开页面或采集价格，定位国对就够了。本指南由 Proxy302 维护，我们也卖这些代理。Proxy302 的 AI 订阅 ISP 是原生的（Claude 档 15 PTC、GPT/Grok 档 10 PTC、Gemini 档 8 PTC，30 天，每档首个半价，1 PTC = 1 美元）；普通静态 ISP 1 天 0.5 美元、30 天 7.99 美元，可以先买一天自己查。

## 标签背后是哪三份记录

| 记录 | 谁维护 | 说明什么 |
|---|---|---|
| 登记国 | 分配这段地址的地区注册机构（ARIN、RIPE NCC、APNIC、LACNIC、AFRINIC），用 `whois` 能查到 | 这段地址的持有人登记在哪个国家 |
| 广播的网络 | 在互联网上宣告这段地址的 ASN；IPinfo 的 `org` 字段会显示 | 流量走的是谁的网络，这个网络自己登记在哪国 |
| 定位国 | IPinfo、IP2Location 等商业定位库 | 定位库认为这个地址在哪里使用 |

三份都写同一个国家，工具就标原生；登记国和定位国不一样，工具就标广播。

## 自己查：三条命令

```bash
# 1. 经过代理查出口 IP、定位国和 ASN
curl -sS --max-time 20 -x "http://USER:PASS@HOST:PORT" https://ipinfo.io/json

# 2. 查这个 IP 的登记记录（203.0.113.24 是文档示例地址，换成你自己的）
whois 203.0.113.24 | grep -iE '^(country|netname|orgname|org-name|descr):'

# 3. 查广播这个段的 ASN 自己的登记（AS64500 是文档示例编号，换成第 1 步 org 里的号）
whois AS64500 | grep -iE '^(country|asname|as-name|orgname|org-name):'
```

SOCKS5 的 IP 第 1 步把前缀换成 `socks5h://`。不同注册机构的 `whois` 格式不一样，把每一行 `country` 都看一下，通常最后打印的那段是最具体的。第 3 步没有国家的话，到 bgp.tools 这类 BGP 查询网站搜这个 ASN，页面会写它登记的国家。

不想敲命令，ping0 这类工具会直接标「原生 IP」或「广播 IP」。不过各家工具判断的权重不完全一样，知道背后这三份记录，遇到两个工具说法不同时心里有数。

## 结果怎么判断

| 登记国 | 定位国 | 广播网络所在国 | 一般标签 |
|---|---|---|---|
| 同一国 | 同一国 | 同一国 | 原生 |
| A 国 | B 国 | B 国 | 广播 |
| 同一国 | 同一国 | 另一国 | 工具说法不一；按「三个都一致」的严格口径，不算原生 |
| 任意 | 几家定位库互相对不上 | 任意 | 先解决定位问题，多查几家库 |

几家定位库国家对不上的情况，可以接着看[代理 IP 查到的国家和买的不一样怎么办](../proxy-ip-location-mismatch-zh/README.md)。

## 什么时候要在意

**值得在意：**

- 你或客户的验收标准就是工具上的原生/广播标签。
- 一个账号长期在一个国家运营，希望登记、定位、网络三方面都指向同一国——毕竟谁都能对这个 IP 跑一次 `whois`。

**没那么重要：**

- 不登录，只看公开页面、查价格、看搜索结果。网站按定位库判断位置，动态住宅本来就一直换地址。
- 你真正想问的是「住宅还是机房」。原生和广播只说地点，不说类型：原生 IP 也可能属于机房公司，广播 IP 也可能被归为运营商网络。类型要另外查，见[双 ISP IP 是什么](../dual-isp-ip-zh/README.md)和[怎么判断住宅、ISP 还是机房](../residential-or-datacenter-ip-check-zh/README.md)。

没有哪个平台公开它看哪份记录，所以「原生」只是一项一致性检查，不代表平台会怎么对待一个账号。

## 广播 IP 是怎么来的

地址段登记在一个地区之后，可以出租或转让给别处的网络使用。登记记录还留在原来的登记国，路由和定位却跟着新网络到了另一个国家，于是几份记录对不上。这在互联网上很常见，本身不代表地址有问题。

## 常见误区

| 误区 | 结果 | 正确做法 |
|---|---|---|
| 没开代理就去查 | 查到的是自己的地址 | 先经过代理拿到出口 IP |
| 按城市判断 | 各家定位库的城市经常不一样 | 按国家判断 |
| 把原生当成住宅 | 两件事 | 类型单独查 |
| 以为标签永远不变 | 登记和定位库都会更新 | 每次查询记下日期 |

## 常见问题

**广播 IP 就是不好的 IP 吗？** 不一定。它只是没通过一项有些人、有些工具在意的一致性检查，要不要紧看你拿它做什么。

**卖家能把广播 IP 改成原生吗？** 登记国只能通过注册机构变更登记来改。定位库接受位置纠错，但改不了登记记录。
