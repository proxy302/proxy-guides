## 挑选清单

| 看什么 | 为什么重要 | 怎么验证 |

| 价格是否公开 | 避免下单后才知道多少钱 | 页面上能看到每个租期的单价 |

## 买前自己做四项检查

1. 在 ARIN、RIPE 或 APNIC 的 WHOIS 查地址段，登记方应是运营商。
2. 在两三个 IP 库里对比类型栏，应是 isp 或 residential。
3. 查反向解析和黑名单。
4. 用 `curl -x http://USER:PASS@HOST:PORT https://ipinfo.io/json` 看 `country` 和 `org`；SOCKS5 用 `socks5h://`。

任何服务商都不该承诺「100% 不被识别」，各家 IP 库判断不同，平台怎么看也不是卖家能决定的。看到绝对保证的措辞，要多留心。
