# 静态 IP 到期了还能继续用原来那个地址吗

到期之前续费，就能一直用同一个 IP；一旦到期没续，这个 IP 就会被释放，之后重新购买拿到的是一个新地址，原来那个不能指望再找回来。所以长期绑着账号、白名单或指纹浏览器环境的 IP，最稳的做法是给它单独打开自动续费，并在到期前几天自己再确认一次。以 Proxy302 为例，静态住宅（ISP）IP 按 1、3、7、30、60、90 天购买，自动续费可以按单个 IP 开关。

*本指南由 Proxy302 维护，我们也销售文中提到的代理。*

## 续费前后会发生什么

| 时间点 | 这个 IP 的状态 | 你要做的事 |
|---|---|---|
| 到期前 | 正常使用，地址不变 | 确认自动续费已开，或手动续费 |
| 续费成功 | 地址不变，使用期顺延 | 一般不需要改配置 |
| 到期且没续 | IP 被释放，原来的账号密码连不上 | 重新购买；拿到的是新地址 |
| 重新购买之后 | 新 IP、新的连接信息 | 把所有用到旧 IP 的地方都换掉（见下文） |

## 怎么避免「到期断线」

1. **按 IP 打开自动续费。** 账号用的 IP 全部打开；只是临时测试用的，可以让它到期。
2. **一次买长一点。** 打算长期用的 IP，直接买 30 天或更长，续费次数少，忘记的机会也少。
3. **记一张对照表。** 每个 IP 绑的是哪个账号、哪个浏览器环境、哪个白名单，到期日是哪天。到期前一周看一眼。
4. **留够余额。** 续费要扣费，到期前确认账户余额够用，否则续不上。

## 已经到期了，换新 IP 要改哪些地方

| 用在哪里 | 要改什么 |
|---|---|
| 指纹浏览器环境（AdsPower、比特浏览器等） | 环境里的代理主机、端口、账号、密码；改完先跑一次代理检测 |
| 手机或电脑系统代理 | 同上 |
| 程序、脚本 | 配置文件或环境变量里的代理地址 |
| 对方的 IP 白名单（接口、后台、服务器防火墙） | 把新出口 IP 加进去，旧的删掉；新地址用 `curl -x http://USER:PASS@HOST:PORT https://ipinfo.io/ip` 查 |

账号这一侧要注意：登录中的账号换了地址，平台可能要求重新验证。新 IP 尽量买在和原来相同的国家；遇到验证就如实完成，代理不能替代验证。之后固定用这个新 IP，别再频繁换。

## 常见问题

**能指定买回原来那个 IP 吗？** 不能保证。到期释放后，新购买按正常流程分配地址。真正在乎这个地址，就别让它到期。

**续费会换 IP 吗？** 不会。到期前续上，地址不变。

**自动续费能随时关吗？** 可以，按单个 IP 开关；关了之后到期就释放。

**短期测试的 IP 也要开自动续费吗？** 不用。1 天 0.5 美元的 IP 本来就是用来测试的，测完让它到期即可；决定长期用，再另买 30 天的并打开自动续费。
