# 静态住宅 IP 怎么选？

先看用途，再核对四件事：账号属于哪个国家、跑几个账号（一号一 IP）、工具要 HTTP 还是 SOCKS5、买之前怎么测。静态住宅 IP（也叫 ISP 代理）在整个租期内地址不变，适合要连续几天、几周反复登录的账号；按流量计费的大批量任务不适合用它。

*由 Proxy302 维护。我们是服务商，不是中立评测方。[English](README.md)*

## 1. 先判断需不需要静态 IP

| 你的用途 | 通常选 | 原因 |
|---|---|---|
| 反复登录同一个账号、店铺或后台 | 静态住宅（ISP）IP | 租期内地址不变 |
| 抓公开网页、查价格或搜索结果，请求很多 | 动态住宅 | 出口会变，按 GB 付费 |
| 流量很大、不需要住宅地址 | 数据中心 IP | 固定、便宜，但网站看到的是机房地址 |

IP 只改变网站看到的网络地址。它不改变平台规则，也解除不了限制或封号。请先读你所用平台的条款。

## 2. 按账号选国家，别按价格选

选账号所属的国家，比如店铺所在的市场，或账号注册时所在的国家，然后保持不变。同一个账号在不同国家之间来回切换，是最容易出问题的习惯，也最容易避免。在 Proxy302，单个 IP 的价格各国相同，所以价格不该影响这个选择。各国有没有货每天都在变，以下单页为准。

## 3. 一个账号一个 IP

每个账号用自己的 IP，并放在自己的浏览器环境或手机里。两个账号共用一个地址，平台看到的就是同一个登录位置。账号有几个，就买几个 IP。

## 4. 按租期买，还是按 GB 买

- **按 IP 租期。** 整个租期内一个固定 IP。截至我们最近一次核对 [proxy302.com/pricing/](https://proxy302.com/pricing/)：1 天 US$0.50，30 天 US$7.99，60 天 US$15.98，90 天 US$23.97。

## 5. 买之前先定 HTTP 还是 SOCKS5

静态 IP 按你选的协议发放，买后不能切换。浏览器、扩展、iPhone 的 Wi-Fi 代理一般用 HTTP；很多指纹浏览器和自动化工具支持 SOCKS5。先看你的工具代理栏支持什么。拿不准时，浏览器环境选 SOCKS5 更灵活，只读标准代理环境变量的工具选 HTTP。

## 6. 先小额测试

先买最小的。Proxy302 最小购买是 1 个 IP 用 1 天，或 1 GB 动态住宅流量。然后：

1. 从下单页或控制台「我的资产」复制主机、端口、用户名、密码。
2. 通过代理访问一个 IP 回显页，例如 `https://ipinfo.io/json`。
3. 确认 `country` 是你买的国家，`org` 显示的是一家互联网服务商。
4. 以国家为准。不同查询服务给出的城市经常不一致。

本仓库第 4 篇有可直接复制的测试命令：[怎么测试代理](../antidetect-browser-with-residential-ip/README.zh-CN.md)。

## 7. 买家清单

- 计费单位：按 IP 加租期，还是按 GB。
- 最小购买量，有没有试用。
- 国家列表，页面有没有区分「列出」和「有货」。
- 提供哪些协议，买后能不能改。
- 续费设置是否由你控制（Proxy302 可以在「我的资产」里按 IP 开关自动续费，下单时留意勾选框）。
- 服务商自己承认哪些事做不到。凡是保证「平台绝不会限制你」的，都要警惕。

## 常见问题

**静态住宅代理和 ISP 代理是一回事吗？** 实际使用中是：登记在消费级互联网服务商名下、地址不变的 IP。见[ISP 代理和住宅代理有什么区别](../isp-proxy-vs-residential-proxy/README.zh-CN.md)。

**能指定城市吗？** 不能保证。城市最多算请求，静态 ISP 按国家选择。

**一个 IP 放几个账号？** 一个。

**用了静态 IP 就不会被限制吗？** 不会。它只提供一个稳定的地址，不改变平台规则。
